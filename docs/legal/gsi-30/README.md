# 국토지리원 측량법 제30조 사용 승인 신청 — 따라 하기

> 대상: `gsi-dem`(基盤地図情報 DEM1A·DEM5A, 2차 메시 533935·533945) + `gsi-dem-tiles`(地理院タイル 標高タイル z14 676장).
> 근거: [承認申請Q&A](https://www.gsi.go.jp/LAW/2930-qa.html) Q2-4(DEM으로 입체 지도 = 제30조 사용 승인), Q4-3(수수료 없음), Q5-1(7–14일), Q5-2(승인번호 상시 표시) — `docs/03-data-sources.md` §6.1.
> 신청은 사람(사용자)만 한다. 이 폴더의 PDF 2개가 첨부 자료, 아래 일본어 블록이 온라인 신청서 입력값이다.

## 첨부 파일 (이 폴더)
| 파일 | 내용 | 크기 |
|---|---|---|
| `gsi30-besshi.pdf` | 別紙(사용 목적·시스템 개요·사용 방법·데이터 구조·출력 방법) + 使用範囲図 | ≈ 0.2 MB |
| `gsi30-sample.pdf` | 完成見本(게임 화면 3장) | ≈ 0.9 MB |

온라인 제한: 파일 1개 5 MB, 합계 8 MB, PDF 권장 → 둘 다 통과. 원본 = `besshi.html`·`sample.html`(브라우저 인쇄 → PDF로 다시 만들 수 있다).

## 1단계 — 사용자 등록 (처음 한 번)
1. [측량성과 원스톱 서비스](https://service.gsi.go.jp/onestop/) → 「ユーザ登録（無料）」.
2. 입력:
   - `ログインID`: 영문·숫자 4–64자 (등록 뒤 바꾸거나 지우지 말 것).
   - `区分`: **個人**(개인 이용). 개인이면 `法人名・機関名`·`代表者役職`·`代表者名`은 **비워 둔다**.
   - `申請者名`(본명), `郵便番号`, `住所`, `電話番号`, `メールアドレス`(2회). 해외 거주면 우편번호 `999-9999`.
3. 「登録確認へ」 → 내용 확인 → 「仮登録完了」 메일의 링크 클릭 → 「登録完了」.

## 2단계 — 신청서 작성 (원스톱 서비스 로그인 뒤)
메뉴 「地図・空中写真、基盤地図情報等の複製または使用承認申請」. 화면 순서와 고를 것:

| 화면 | 고를 것 / 입력 |
|---|---|
| 2-1 이용할 지도 등 | **国土地理院**의 성과 → 「次へ」 |
| 2-2 이용 목적 | 인터넷 공개(Web 사이트·시스템/애플리케이션)에 가장 가까운 항목 → 흐름 확인 → 「次へ」 |
| 2-3 가공 방법 | **使用**(「複製」 아님 — 기반지도정보로 지도 등을 만드는 것은 使用) → 「次へ」 |
| 4-1 사용 목적·작업 방법 | ① 자동 입력 확인. ② 가공 체크박스 = 「標高データから新たに3Dの地形を作成」에 해당하는 항목(데이터 가공·새로 작성). 자유 기술란에 아래 **[使用目的]**·**[使用方法]** |
| 4-2 측량 지역·사용 기간 | ④ **[測量地域]**, ⑥ **[使用期間]** |
| 4-3 사용 성과·완성품 | ⑦ 성과 종류 선택: 基盤地図情報 → 数値標高モデル → **1mメッシュ** 533935·533945, **5mメッシュ** 533935·533945. 標高タイル 항목이 목록에 없으면 「その他」에 **[その他の成果]**. ⑧ 최신판 질문 = 최신판 사용(※ 아래). ⑨ 「高度な精度を要する」 **체크 안 함**. ⑩ **[完成品の縮尺及び名称]** |
| 4-4 신청자·작업자 | ⑪ 計画機関 = 신청자 본인 → ⑫ 「申請者に同じ」. ⑬ 作業機関 = 「申請者に同じ」. ⑭ **[成果入手年月日]**. ⑮ 메일 자동. ⑯ **[備考]**. ⑰ 公共測量 **체크 안 함** |
| 첨부 | 「ファイル選択」 → `gsi30-besshi.pdf`, `gsi30-sample.pdf` → 「申請」 |

- 입력 30분을 넘기면 오류가 날 수 있다 → 아래 블록을 미리 열어 두고 복사·붙여 넣기. 중간에 「保存」(XML)도 된다.
- ※ ⑧ 최신판: 우리 파일은 2026-09-27에 받은 그 시점 최신(작성일 2025-08-22). 화면에 이 메시의 더 새 판이 보이면 새 판을 고르고 알려 줄 것(데이터를 새 판으로 다시 받아 재빌드).

### 입력값 (그대로 복사)

**[使用目的]**
```
Webブラウザで動作する無料の3D散策ゲーム「TOKYO SANPO」（https://earthaimap.com）において、東京の地形を立体的に再現するため。インターネット上で広く一般に無料で公開する。詳細は別紙のとおり。
```

**[使用方法]**
```
基盤地図情報 数値標高モデル（1mメッシュ、欠測部のみ5mメッシュ）を1m間隔の格子に再標本化し、建物の底面の平坦化・車道の横断勾配等の成形を行った上で、表示用の簡略化した3D地形メッシュと物理演算用の高さ格子を作成する。標高タイルからは遠景用の簡略化した3D地形メッシュを作成する。作成したデータをWebサーバに保存し、ゲームの3DCGとして閲覧者の画面に表示する。標高値を数値で表示・出力する機能はない。詳細は別紙のとおり。
```

**[測量地域]**
```
東京都渋谷区・新宿区周辺（基盤地図情報 2次メッシュ 533935、533945）及び東京23区を中心とする約52km四方（地理院タイル 標高タイル z14 676枚）。別紙の使用範囲図のとおり。
```

**[使用期間]** (일수 입력이면 `365`)
```
承認後1年間
```

**[その他の成果]** (標高タイル이 선택 목록에 없을 때)
```
地理院タイル 標高タイル（基盤地図情報 数値標高モデル、dem_png）ズームレベル14、x=14541〜14566、y=6436〜6461（676枚）
```

**[完成品の縮尺及び名称]**
```
「TOKYO SANPO」（ブラウザ3D散策ゲーム） 縮尺：3D表示のため固定の縮尺なし（視点に応じて連続的に変化）
```

**[成果入手年月日]**
```
2026年9月27日（数値標高モデル 1m・5mメッシュ）、2026年9月29日（標高タイル）
```

**[備考]** — 첫 줄은 본인 정보로 바꿀 것. 둘째 줄(이미 공개 중)은 넣기를 권장(사실대로 알리는 편이 안전) — 넣을지는 본인 판단.
```
連絡先：（氏名） TEL：（電話番号）
本ゲームは2026年10月19日から公開しています。承認後、画面右下の出典表示とクレジット画面に承認番号を併記します。
```

## 3단계 — 신청 뒤
1. 「申請」 → 완료 화면 + **申請ID** 확인 메일.
2. 심사 7–14일(토·일·공휴일·연말연시 제외). 심사계가 전화·메일로 보정을 요청할 수 있다 → 내용을 Claude에게 전달.
3. 승인 메일 `法第30条「測量成果の使用承認申請」承認完了（申請ID）` + **承認書** 첨부 → 승인서의 **承認番号**와 표시 문구(出所 표기)를 그대로 Claude에게 전달.
4. Claude가 화면 오른쪽 아래 상시 출처 줄(`apps/game/src/credits.ts`)·지도 화면·크레딧·`content/ATTRIBUTION.json`·`docs/03`에 넣고 PR → production 배포(GitHub 승인은 사용자).
5. 성과 제출: 공개 URL(https://earthaimap.com)을 [成果の提出](https://www.gsi.go.jp/LAW/2930-seika.html) 페이지의 메일 주소로 보낸다(승인번호 포함).
