# ADR-0054: 가상 간판 = 생성 브랜드 사전(실존 대조) + 색까지 구운 아틀라스(Noto Sans JP, 파이프라인 래스터) + props.inst 간판 3종 + 간판 필드 (M05-T06)
- Status: Accepted
- Date: 2026-10-02

## Context
M05-T06: 가상 브랜드명 사전(가나/한자/영문, 실존 상호 필터링 목록 대조), 간판 유형(돌출 간판, 입간판, 창문 시트, 옥상 광고탑), 아틀라스 굽기, 건물 용도별 배치.
수락 = 실존 상표 목록 대조에서 일치 0건, 상점가 밀도 사진 대비 유사. 03 §5: 실제 로고·상표·점포 간판 금지. 로드맵 Files는 `content/signage/brands.yaml`.

## Decision
1. **브랜드 사전**(`stages/signage/brand-generator.ts`): `content/signage/brands.json`(YAML 대신 JSON — 파이프라인 설정이 모두 JSON, 의존성 추가 없음) 설정 → 결정론 rng로
   가타카나·히라가나 2–3음 / 한자 두 자(둘째가 屋·堂·亭… 이면 업종 생략) / 로마자 음절 + 업종 말(珈琲·ラーメン·薬局… 24종) 64개. `content/signage/real-brands.txt`(편의점·외식·약국·
   백화점·은행·가전·의류·주요 기업 254개 표기)와 **정규화(NFKC·소문자·가타카나→히라가나·기호 제거) 대조**: 2자 이하 완전 일치, 3자 이상 포함(이름 핵심이 실존 이름 안에 있어도) → 버림. 결과 64/64, 일치 0건.
2. **글꼴·아틀라스**(`stages/signage/{raster,atlas,run}.ts`, `pnpm pipeline signage`): Noto Sans JP Bold(OFL, noto-cjk 태그 Sans2.004 서브셋 OTF, sources.lock sha256) 윤곽을
   opentype.js(MIT)로 읽고 **자체 래스터라이저**(곡선 꺾기 + 0이 아닌 감기, 하위 주사선 5개·가로 정확 덮임)로 굽는다. 1024 × 2048 sRGB PNG(400 KB): 브랜드마다 가로 타일 256 × 64(4:1)·
   세로 타일 64 × 256(1:4, 한 자씩 위→아래, 장음 ー → ｜). 타일 = 둥근 판(밖 = 틀색) + 팔레트 바탕·강조 띠·글자 합성 — **색까지 구워** 렌더는 표본 1회(팔레트 uniformArray 2개를 쓰던 첫 구현은
   파사드 셰이더의 단계당 uniform 버퍼 12개 한도를 넘겨 파이프라인 생성 실패). 글꼴 파일은 게임에 배포하지 않는다.
3. **배치**(`derive/props/signs.ts`, props.inst `PROP_TYPE` 16 돌출·17 입간판·18 옥상 — 형식 그대로, 추가만): 상업·업무 용도 건물 지면 링의 길가 변(자판기와 같은 `streetEdges`)을 따라
   - 돌출 간판(袖看板): 9 m(± 절반)마다 벽면에 상자(2.2 × 0.55 m, 4:1 세로 타일)를 3.6 m부터 2.5 m 간격으로 1 ~ 6개(맨 위 ≤ 건물 높이 − 1 m), 바깥 1.2 m가 다른 건물이면 생략.
   - 입간판: 10 m마다 45 %로 벽에 붙여(뒤 틈 0.08 m — 캐릭터가 끼는 틈 없음, ADR-0051) 박스 콜라이더.
   - 옥상 광고탑: 높이 ≥ 14 m 건물 30 %, 가장 긴 길가 변 안쪽 1.5 m 지붕(그 점의 지붕 면 높이) 위, 폭 = min(변 × 0.7, 14 m) → scale = 폭 / 10.
   브랜드·크기 변형은 렌더가 **WF 위치 해시**로 고른다(셀 무관 결정론, 형식 변경 없음).
4. **렌더**(`internal/signs/*`): 간판 필드 = 종류별 풀 1개(Mesh + InstancedBufferGeometry, `_ipos`·`_isig` — ADR-0052와 같은 이유), 15 m 이동·셀 변경 때 거리(돌출 320·입간판 120·옥상 1500 m) 안을
   가까운 순으로 용량(6144·1536·512)까지. 머티리얼 `sign` 하나(면 `_face` 1 세로·2 가로 타일 = 아틀라스, 틀 = 짙은 금속). 파사드 1층 간판 띠(facade/retail)는 같은 아틀라스 노드:
   베이 가운데 4:1 간판(≤ 3.4 m) + 나머지 띠 = 그 브랜드 바탕색(표본), 적재 전 = 기존 무지 색판. 에셋은 첫 표시 뒤 지연 적재(`signsSettled` = 골든뷰 조건).
5. 창문 시트(窓シート)는 미구현(파사드 창 셰이더에 표본 추가 — 성능 확인 뒤, M09 야간 점등과 함께) — ⚠️.

## Consequences
- 로고·실존 상호 없음을 사전 단계에서 보장(대조 목록은 추가만 하면 다음 `signage`에 반영). 렌더는 문자열을 모른다(아틀라스 타일 번호만).
- 셀당 간판 인스턴스: 시부야 센터가이 셀 730 돌출 + 64 입간판 + 11 옥상(예산 5k 안). 야간 발광·점등은 M09.
