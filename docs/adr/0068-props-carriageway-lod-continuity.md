# ADR-0068: 소품 차도 정착·validate 검사, 소품 풀 `_itype` 업로드 범위, L1 랜드마크 = L0 모양
- Status: Accepted (M07 사전 ⓪)
- Date: 2026-10-05

## Context
staging(`20261004-ed3d33c-8de63322`) 사용자 확인에서 두 문제: (1) 넓은 가로수 대로(오모테산도·메이지도리) 차도 한가운데 공중전화·버스 정류장·자판기 등 소품,
(2) 멀리서 보이던 직육면체가 가까이 가면 사라짐(위치 모름 — 소품·차량·군중·HLOD 중 어느 원근 전환인지 미상).

조사:
- (1) `derive/props/points.ts offCarriageway`가 차도 위 OSM 점을 **6 m 안 보도**로만 옮겼다 — 보도가 더 먼 넓은 간선(36 m 오모테산도) 한가운데 점, 보도 없는 생활도로 점은 그대로.
  옛 빌드 전 셀 검사(아래 validate): 지상 소품 30,872개 중 **차도 위 818**(stop 표지 354·버스 정류장 220·자전거 거치대 48·우체통 42·공중전화 32·자판기 31·…),
  보도 위 길가 기둥 중 연석 0.3 m 안 **131**(stop 표지 47·가로등 39·버스 정류장 32·차량 신호 12·전주 1).
- (2) 데이터 쪽부터: 레벨별 위에서 본 건물 덮임 비교(2 m 래스터) — L1에만 있고 L0에 없는 조각은 영역 가장자리(이웃 셀 소유)와
  **요요기 체육관**(L1 = PLATEAU 30 m 프리즘, L0 = 랜드마크 텐트 처마 5–6 m)뿐. 셀 메시 경계(boundsLocal) 1,784 프리미티브 오차 0(절두체 컬링 아님).
  실제 GPU **거리 스윕**(대상 소품을 앞에서 내려다보며 300 → 10 m, 레이어 보임/숨김 3장 → 화면 중앙 창 픽셀 차, 잡음 = 숨기기 전 두 장 차): 공중전화·버스 정류장이
  55 m까지 보이다 **40 m(LOD0 띠)부터 0 px**, 같은 위치로 바로 순간이동하면 보임 — 재현이 이동 경로에 따라 달랐다.
  원인: `PropField.updateSignals`가 신호 램프가 바뀐 슬롯만 올리려고 `_itype.clearUpdateRanges()` → 같은 프레임의 풀 재작성(`writeInstances`, [0, n)) 범위를 지움.
  재작성은 램프 칸을 0으로 되돌리므로 신호가 섞인 풀은 **재작성 때마다** 램프가 "바뀌어" 덮어쓴다 → 다른 인스턴스의 `_itype`(종류)가 GPU에서 옛 값 →
  `_ptype ≠ _itype` 정점은 원점으로 퇴화(소품 셰이더) → 그 소품이 안 그려지거나 다른 종류로. LOD 띠가 바뀔 때(가까이 갈 때) 재작성되므로 "멀리서 보이다 사라짐".

## Decision
1. **소품 정착** `derive/props/curb.ts`: `SiteTest`(건물 발자국 = 비차도) + `nearestSide`(32방위 링) — 차도 위 점은 25 m 안 가장 가까운 비차도 쪽으로:
   보도면 연석 뒤 `WALK_BACK_M` 0.5 m(보도가 좁으면 폭 가운데까지 — `behindCurb`), 보도 없는 길(건물·공지 가장자리)이면 가장자리 안쪽 `ROADSIDE_IN_M` 0.4 m.
   보도 위인데 연석에 붙은 점은 차도 반대쪽으로. OSM 점(거치대 모듈마다)·보행/차량 신호기·보도 쪽 전주에 적용(전선은 정착된 전주 위치를 쓴다).
2. **validate `props on road`** `stages/validate-props.ts`(CLI 오류): L0 지상 소품(맨홀·벽면/옥상 간판 제외)이 PLATEAU 차도 폴리곤 위면 오류 —
   예외 = 보도 없는 길가(가장 가까운 비차도가 건물·공지이고 ≤ `EDGE_M` 1 m). 보도 위 길가 기둥(신호·표지·전주·가로등·버스 정류장)이 차도에서 < `CURB_BACK_M` 0.3 m면 `curbTight` 오류.
   같은 판정 함수를 파생과 검사가 함께 쓴다(검사 입력은 정규화 도로·건물 — 빌드 결과 props.inst를 다시 읽음).
3. **소품 풀 업로드 범위 합치기** `props/pools.ts mergeUpdateRange`: 램프 범위는 대기 중 범위와 하나로 합친다(지우지 않는다). 단위 회귀 + e2e.
4. **L1 랜드마크** `hlod/l1.ts`: 자식 L0 셀의 랜드마크를 L0와 같은 함수(`overrides/index.ts emitLandmarks` — 셸 + 부품, 옥상 설비·교량 제외)로 만들어 L1 건물 스트림에 넣고,
   대체 건물(renderSkip)은 단순화 입력에서 뺀다(공공 파사드 단색). `runHlod({ overrides })` ← CLI `readOverrides`.
5. **디버그 API** `RenderService.debugLayerVisible(layer, visible)`(props·signs·trees·crowd·farCrowd·vehicles) + e2e `lod-continuity.spec.ts`:
   world-mini 자판기 2개(실제 GPU 스캔에서 네 거리 모두 앞이 트인 것)를 100·60·34·16 m에서 소품 보임/숨김 캔버스 차(Node PNG 디코드) ≥ 거리별 최소(4·10·25·110 px, 480×270).

## Consequences
- 단위: 36 m 간선 한가운데 공중전화 → 보도(연석 뒤 0.5 m), 보도 없는 길 stop 표지 → 가장자리 0.4 m 안, 연석 0.05 m 가로등 → ≥ 0.3 m, 간선 픽스처 지상 소품 차도 위 0.
  부분 빌드 9셀(오모테산도·메이지도리·L0_-7_-17 등): 차도 위 0·연석 0. MVP 전체 결과는 PROGRESS(재빌드 validate).
- e2e(SwiftShader): 수정 뒤 9·29·77·321 / 8·22·56·240 px, 회귀 재현(범위 덮어쓰기) 1·5·17·32 / 0·2·34·135 px → 실패 확인.
- 실제 GPU 스윕(RTX 3050 Laptop, 21–23 W): 수정 뒤 공중전화·버스 정류장·자판기·우체통·가로등·전주·간판 3종 거리별 연속(남은 0 px는 건물에 가린 시점 — 저장 프레임으로 확인).
  staging 옛 코드 같은 시점 40·28·18 m에서 공중전화·벤치 소멸 재현(docs/screenshots/M07/pre0).
- L1 체육관 = 텐트(처마 ≈ 6 m, 기둥 끝 그대로) — 원경 실루엣 높이 유지, L0 전환 때 모양 점프 없음. 랜드마크 면은 원경 단색 파사드.
- 신호 차량 신호기는 정착 뒤 위치가 최대 수십 cm 바뀐다(nav·신호 코드 불변 — 같은 빌드에서 함께 생성).
