# ADR-0112: 원경 나무 = L1 셀 trees.inst + L0 겹침 숨김
- Status: Accepted
- Date: 2026-11-27

## Context
- 나무는 L0 셀 trees.inst에만 있어 L0 반경(≈ 384 m) 밖은 나무가 없다. 상공에서 공원·가로수가 맨땅으로 보인다(그래픽 분석 S6).
- 형식은 이미 trees.inst를 L1에 허용한다(05 §4 levels [0, 1]). 렌더 TreeField는 64 m 블록 + 거리 띠(상세 30 m · 간략 60 m · 임포스터 2 km).

## Decision
1. 파이프라인 hlod: L1 셀 = 자식 L0 16개의 trees.inst를 L1 원점 기준으로 합친다(관목 제외 — 원경에서 안 보이고 수가 많다). 섹션은 L0와 같이 gzip, 출처 = 자식 섹션 합집합.
2. 렌더 TreeField: L1 셀 나무를 1024 m 셀 기준 64 m 블록(16×16)으로 나누고, 블록마다 소속 L0 셀(256 m 격자)을 기억 → 그 L0 셀 나무가 들어와 있으면 그 블록은 그리지 않는다.
   L0 셀이 들어오거나 나가면 해당 L1 블록의 풀만 다시 채운다. 통계 `instances` = 실제로 그릴 나무.

## Consequences
- 384 m 밖에서도 공원·가로수가 임포스터로 보인다(L1이 있는 ≈ 1.5 km까지, 임포스터 띠 2 km 안). L1 셀 크기 증가 = 나무 24 B × 수(gzip).
- 임포스터 풀 용량 65,536 — 원경 나무가 많은 곳에서 넘치면 `dropped`로 보인다(통계).
- L2 이상은 나무 없음(4 km 셀 — 임포스터 띠 2 km 밖).

## Alternatives
- 원경 지면에 수관 무늬만 칠하기 → 입체감 없음 → 기각(토지피복 녹지 색은 M12-T04가 이미 한다).
- L1 HLOD 메시에 나무 덩어리 기하 굽기 → 계절·바람 표현 불가, 메시 크기 증가 → 기각.
