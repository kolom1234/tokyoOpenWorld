# ADR-0060: 첫 표시 단축 = 선컴파일을 렌더 생성 직후 시작 + 스폰 셀 대기 그룹 컴파일(겹치기)
- Status: Accepted (M06 사전 결정 4, 사용자 2026-10-02 — M02 기준 첫 표시 ≤ 12 s)
- Date: 2026-10-04

## Context
M05-T08 staging 측정 첫 표시 13.8 s ⚠️(기준 ≤ 12 s). 측정(실제 GPU RTX 3050 Laptop 30 W, 2560×1440, 새 컨텍스트 = 캐시 없음, `bootprobe.mjs`):
- **측정 민감도**: 다른 GPU 작업이 돌면(같은 PC의 앱 내 브라우저 패널이 게임을 렌더하던 상태 — GPU 사용률 39 %) staging 첫 표시 **29.9–33.1 s**(선컴파일 16.9–18.1 s),
  유휴 상태 **9.8–10.0 s**(선컴파일 4.5–5.0 s). 13.8 s도 부하가 섞인 값으로 본다 → 측정 때 GPU 사용률 0 % 확인 필수(14 §2 메모).
- 유휴 단계 분해(staging): JS·caps ≈ 1.2 s → 첫 렌더 초기화 0.5 s → world.json·cells.idx ≈ 1.7 s → **선컴파일 5.0 s**(그동안 스트리밍 시작 안 함) → 셀 9개 다운로드·디코드·적용 ≈ 2.7 s.
- 긴 프레임(rAF 간격): 선컴파일 동기 노드 빌드 ≈ 2.3–2.5 s(메인 스레드), 그 뒤 **셀이 처음 그려지는 프레임 1.45 s**(새 렌더 객체 노드·파이프라인 동기 생성 — 머티리얼은 공유인데도).

## Decision
1. **선컴파일을 렌더 생성 직후 시작**(`createWorldView`) — world.json 조회와 겹친다. `showWorld`는 그 Promise를 기다린다.
2. **스트리밍을 선컴파일과 동시에 시작**하고, 렌더 `stageCells(true)`: 대기 중 addCell의 셀 슬롯 그룹은 장면 밖 그룹에 둔다(그리지 않음).
   스폰 영역 whenReady(전부 live — ack는 addCell 때) 뒤 `compileStaged()`(= `renderer.compileAsync(대기 그룹, 카메라, 장면)`)를 선컴파일 남은 비동기 구간과 겹치고,
   둘 다 끝나면 `commitStaged()`로 원래 부모에 붙인다. 소품·나무·간판 풀은 대상 아님(이미 선컴파일). 원점 재설정·제거는 대기 중에도 그대로 동작.
3. 선컴파일 단계별 로그 `precompile atmosphere · materials · avatar`, `staged cells compiled (N groups) ms`.

## Consequences
- 로컬 같은 빌드(스폰 3×3, dev 서버, 콜드 컨텍스트 3회): 첫 표시 9.71–10.09 s → **7.62–8.44 s**. 셀 첫 프레임 멈춤 1.45 s → 0.2 s(대기 셀 컴파일 1.8–2.1 s는 선컴파일과 겹침).
  선컴파일 시작을 앞당기자 대기 LUT가 월드 조회·첫 렌더와 겹쳐 0.3 → 1.2–2.6 s로 늘었다(전체는 이득).
- 남은 임계 경로 = 머티리얼 선컴파일(4–5.5 s, 그중 동기 노드 빌드 ≈ 2.3 s — 파사드 셰이더). 더 줄이려면 첫 화면에 안 쓰는 변형(HLOD 디더·프리패스)을 첫 표시 뒤로 미루거나
  셰이더를 나눠야 한다(끊김 위험 — 보류).
- **staging**(MVP `20261004-f0ae5ab-8de63322`, 코드 459c0de, 유휴 GPU 0 %, 콜드 3회): 첫 표시 **8.46–8.59 s**(M05 빌드 9.8–10.0 s), 첫 표시 전 전송 36.2–39.6 MB(예산 60 MB).
  처음엔 스폰 셀이 일찍 준비되며 exclusive가 끝나 선컴파일 동안 HLOD·주변을 받아 71–91 MB → `whenReady.holdExclusiveUntil = 선컴파일`로 첫 표시까지 선적재 보류.
  M05(21 MB)보다 큰 것은 스폰 반경 384 m 대상 셀이 대기 그룹으로 먼저 다 들어오기 때문(75그룹).
- 앞서 시험한 "렌더 적용만 선컴파일 뒤로 미루는 관문"은 셀 첫 프레임 멈춤을 못 없애 효과가 없어(9.67–9.86 s) 대체했다.
