# ADR-0111: PLATEAU 텍스처 = 측정 자료 → 건물별 tintIdx·커튼월 (셀 형식·셰이더 변경 없음)
- Status: Accepted
- Date: 2026-11-27

## Context
- 파사드 색·재질은 건물 해시로 정했다(`facade-params.ts` — tintIdx = 해시, 커튼월 = 높이 + 해시 40 %). 실제와 무관하다(그래픽 분석 D3).
- PLATEAU LOD2 건물 다수가 항공 사진 기반 텍스처를 가진다(리더가 `tex`·`uv`까지 정규화). 그대로 띄우면 해상도·그림자·원근 왜곡·셀 크기 문제(분석에서 기각).
- 렌더는 tintIdx 하나로 (벽 그룹 → 레이어) × 팔레트를 고른다(해시 기반). 형식을 바꾸지 않고 이 선택을 실제 색에 맞출 수 있다.

## Decision
1. **측정**(`facades --prep`, 컨테이너): 영역 L0 건물이 쓰는 appearance 폴더만 PLATEAU zip에서 풀어(컨테이너 /tmp — 바인드 마운트는 느리다) ImageMagick으로 256 px PPM.
   벽 면마다 UV 외곽 다각형 안 20×20 격자 표본: 선형 휘도 < 0.06 = 유리·창, > 0.85 = 하이라이트(제외), 나머지 = 벽 → 면 중앙값. 건물 = 면 넓이 가중(벽 색·유리 비율).
2. **선택**(build·hlod 시작 때 `loadFacadeMeasures`): 재질 매니페스트(레이어 평균 sRGB)로 렌더 결과를 tint 0..255마다 예측
   (셰이더와 같은 `facadeWallGroup`·`facadeLayerIndex`·팔레트·wallFloor 0.08·얼룩 평균 0.098) → 측정 색(전체 노출 보정: 측정 휘도 중앙값 → 예측 중앙값)과
   CIELAB 거리(밝기 가중 0.5 — 조명 영향) 최소 tint. 커튼월 = 오피스 & 유리 ≥ 0.45(90 m 이상은 ≥ 0.3). 측정 없는 건물 = 예전 해시.
3. 레이어 선택 표(벽 그룹 후보·팔레트)와 TSL hash CPU 짝 `tslHash`를 `@sanpo/core`로 옮겨 셰이더와 파이프라인이 같은 값을 쓴다.
4. `facadeParams`가 모듈 등록을 조회 → L0·L1·조명·오디오가 같은 tint(전환에서 색 불변).

## Amendment (2026-11-27, 전체 빌드 골든뷰 뒤)
- 첫 전체 빌드(`20261126-7784be4`)에서 색만으로 tint를 고르자 벽 그룹이 몰렸다(오피스 metal 23 % → 69 %, 맨션 plaster 78 %) → 서신주쿠 근경이 같은 금속 패널로 뒤덮임. 저층 오피스는 띠창(어두운 창 띠)도 유리 ≥ 0.45라 커튼월이 됐다.
- 수정: ① 벽 그룹(재질 종류)은 사진 색으로 알 수 없다 → **해시 tint의 그룹을 유지**하고 그 그룹을 내는 tint 중에서만 색을 맞춘다(그룹 분포 = 예전 해시 그대로).
  ② 노출 보정에 **회색 세계 화이트밸런스**를 더한다(측정 채널 중앙값 → 무채색, 항공 사진의 푸른 기 — 채널 배율 2.94/2.47/2.29). ③ 커튼월은 **35 m 이상** 오피스만(예전 해시 규칙과 같은 높이 문턱).

## Consequences
- 텍스처가 있는 건물의 벽 색·유리감이 실제 건물에 가까워진다. 셀 크기·요청·셰이더 비용 0. 재질 라이브러리를 바꾸면 tint 선택도 바뀐다(재빌드 필요).
- 팔레트 8 × 레이어 몇 개 조합 안에서만 고르므로 강한 원색·특수 마감은 근사. 텍스처 조명(그늘 면)·JPEG 색 왜곡은 중앙값·전체 노출 보정으로만 완화.
- 측정 파일(`data/derived/facades/measures.json`)은 원천 데이터 파생 — 커밋하지 않고 sources.lock + 파이프라인으로 재현.

## Alternatives
- PLATEAU 텍스처를 근거리에 직접 표시 → 해상도·그림자·셀 크기·요청 증가 → 기각(분석 단계).
- `_FACADE`에 측정 RGB를 추가(형식 변경) → 정확하지만 L0·HLOD 형식·셰이더·호환 변경 → 기각(tint 선택으로 충분, 필요하면 재검토).
- AI 텍스처 생성 → 출처·라이선스·일관성 문제 → 기각.
