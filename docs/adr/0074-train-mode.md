# ADR-0074: train 모드 — 칸에 붙은 카메라(서기·좌석·전면 전망) + 차내 보행은 walk, LCD = 화면 오버레이, 빨리감기 = 시계 점프, 경계역 자동 하차
- Status: Accepted (M07-T05)
- Date: 2026-10-05

## Context
M07-T05 Do: 서기/좌석/전면전망 뷰, "다음 역까지 빨리감기", 차내 LCD 안내(다국어), MVP 경계역 자동 하차. Accept: 시부야→신주쿠 연속 탑승 중 스트리밍 정지 0, 전면전망 60 fps.
09 §1 초안: walk → (칸 안 센서 + 정차) → train(standing/seated/frontView), 정차 중 출입구 밖 = walk. T04로 칸 바닥이 캐릭터를 실어 나른다(ADR-0073).
열차 위치는 메인 스레드에서 프레임마다 정확(ADR-0072) — 카메라를 칸에 그대로 붙일 수 있다. 실제 안내 방송·문구 사용 금지(사용자 규칙).

## Decision
1. **역할 나눔**: 차내에서 걷기 = **walk 모드 그대로**(물리 칸 바닥 — 입력은 바닥 기준 상대 속도). train 모드 = 칸에 붙은 카메라(`camera/attached-rig.ts` — 칸 로컬 오프셋·칸 기준 시선·속력 비례 미세 진동 상하 4 mm·좌우 3 mm,
   스무딩 없음) + HUD. 시점: standing(문 옆 눈높이 1.6 m)·seated(롱시트, 통로 쪽을 봄)·frontView(선두 칸 운전실 왼쪽 눈높이 — LOD0 전면 유리 구멍), V 순환. 입력 컨텍스트 = vehicle.
2. **승차**: walk 중 F + 발이 칸 안(칸 자세 기준 폭·길이·바닥 높이) → train(standing, 그 칸). 원격 진입 = `request('train', {tripId, car?, view?})`(디버그·테스트·탑승 측정).
3. **하차**: 문 열린 정차에서 F, 또는 트립의 마지막 정차(MVP 경계역 — 시부야·신주쿠, 선로 정차 목록이 MVP 역만이라 마지막 = 경계) = "미개방 구역" 안내 4 s 뒤 자동.
   자리 = 그 칸 승강장 쪽 가장 가까운 문 앞 0.9 m·차 바닥 − 0.05 m → `ModeOutput.next = walk`(`WalkParams.exact` — 지면 탐색 없이 그 자리에 바디). 트립이 끝나면(운행 종료) 마지막 자세에서 하차.
4. **빨리감기(T, `ButtonAction 'skip'`)**: 페이드 아웃 0.35 s → `jumpClock(다음 역 도착 − 8 s)` → 검은 화면 0.5 s(스트리밍 따라잡기) → 페이드 인 0.35 s. 열차·문·시간표는 시각의 순수 함수라 바로 재배치(따로 맞출 상태 없음).
5. **안내 화면(LCD 풍)**: 게임 `train-lcd.ts` DOM 오버레이(장면 텍스처 아님) — 노선색 띠 + 노선·방향(자체 문구: 外回り/Outer loop/외선 순환 …), 다음 역/정차 역, 도착까지 분, 문 쪽, 경계역 안내,
   일본어 → 영어 → 한국어 4 s 순환. 역·노선 한국어 이름 = rail-lines.json `name.ko`(rail.bin 메타 추가 필드). 차임·음성은 M09(오디오).
6. **스트리밍**: train 모드 관심점 = 카메라 + 진행 방향 4 s 앞(lookahead, 가중 0.8).

## Consequences
- **수락(실제 GPU — RTX 3050 Laptop, 1600 × 900 High, 충전·최대 성능, 로컬 `20261005-962ed6c-aefbe9ff`)**: 시부야 12:03:21 출발 → 하라주쿠 → 요요기 → 신주쿠 도착 → 안내 4 s → 자동 하차(승강장 위 walk),
  전면 전망 1배속 연속 6분: 탑승 구간 19,719프레임 평균 **59.9 fps**, p50/p95/p99 = 16.67/16.79/16.91 ms, 최대 50 ms 1회(33 ms 초과 3프레임), GPU 22.6 W,
  **지면 공백 0**(1 s마다 카메라 아래·진행 방향 200 m 앞 L0 지면 높이 — 357표본), 스트리밍 큐 0–1(첫 적재 뒤). 측정 중 다른 부하(테스트 실행)가 겹친 회차·15 s마다 스크린샷을 찍은 회차는 그 구간만 끊김 — 깨끗한 회차 값을 기록.
- 빨리감기(실제 GPU): 시부야 정차 중 T → 0.35 s 페이드 → 12:03:06 → 12:04:43(하라주쿠 도착 8 s 전) 점프·1.4 km 이동 → 지면 0.1 s 안 적재 → 페이드 인, 열차는 감속 중 그대로 이어 달린다.
- 차내 화면(차체 안 LCD 면)에는 글자를 그리지 않는다(빈 발광 면) — 화면 오버레이로 대신.
- train 모드 중 물리 바디는 원래 자리(칸 안이면 같이 실려 감, 원격 진입이면 그대로) — 하차 때 승강장으로 옮긴다.
- 역은 PLATEAU 역사 껍질이 운전실 시야를 일부 가린다(하라주쿠 — ADR-0073 ⚠️).
