# ADR-0031: 지형 표면 분류 `_SURF`와 지면 스플랫·젖음 (M03-T06)
- Status: Accepted
- Date: 2026-09-29

## Context
05 §4는 terrain.mesh에 정점 속성 `_SURF`(u8 8클래스)를 두었지만 M01–M03-T04 빌드는 전부 7(plaza)이었다. 07 §4 M_TERRAIN·M_ROAD는
`_SURF` 스플랫·경사 triplanar·아스팔트 변형·젖음을 요구하고, 수락 기준은 "반복 타일링이 30 m 거리에서 식별되지 않음"이다.
도로 전용 메시·연석·차선(M05-T01)과 녹지·수면·철도 데이터(M05)는 아직 없다. 젖음 값을 줄 sim 날씨(M06)도 없다.

## Decision
1. **분류 출처 = PLATEAU 도로 폴리곤(정규화 `roads/<cellId>.ndjson.gz`)**: 셀 + 8-이웃의 조각을 257² 1 m 격자에 스캔라인(짝-홀)으로 칠한다
   (`surface-class.ts`). 차도·기타·횡단보도 → 0 asphalt, 교통섬·보도 → 1 sidewalk(뒤가 이김), 나머지 → 7 plaza.
   이웃 조각까지 넣어 셀 경계 샘플을 양쪽 셀이 같은 입력으로 분류한다(정규화 조각은 셀 사각형으로 잘려 있어 경계 행이 반열림 규칙에 걸린다).
   2 grass·3 soil·4 gravel·5 water·6 ballast는 M05 데이터가 들어올 때. HLOD(L1–L3) 지형은 7 고정.
2. **RTIN 분류 경계 세분**: 차도(0)와 나머지의 경계를 덮는 삼각형은 1칸(1 m), 그 밖의 분류 경계는 4칸까지 강제 분할(`terrain-rtin.ts` `edgeKeyOf`).
   2 m로 두면 보도 띠(2–4 m)가 정점 보간 때문에 물결 모양이 됐다. 높이 오차 5 cm 규칙·경계 정점 잠금은 그대로.
3. **셰이더 스플랫(`materials/terrain.ts`)**: 정점 원-핫 8개(vec4 varying 2개) 보간 → 픽셀마다 상위 2클래스.
   경계 혼합은 **클래스 번호 순서에 반대칭인 노이즈**(주/보조가 바뀌는 선에서도 연속). 주 클래스 = 위 투영 2표본(0.83 rad 회전·0.61배 축척,
   ≈ 6 m 노이즈 가중, 분산 보존 혼합 m + (mix − m)/√(w²+(1−w)²)), **법선은 첫 표본만**. 보조 클래스 = 알베도·ORM 1표본(법선은 기하 쪽으로).
   경사면 측면 투영(수평 법선의 접선 u·높이 v, n.y 0.85→0.6)은 `TerrainOptions.triplanar`(기본 끔, 품질 티어 M03-T08).
   표본 = 알베도·ORM 3쌍 + 법선 1 + 노이즈 4 = 11.
   **노이즈 = 256² RGBA 격자값 텍스처**(`noise.ts`, core rng 결정론) 4축척(1.2·3.3·9·29 m) × 4채널 = `noiseBank` 표본 4회.
4. **M_ROAD 변형은 노이즈만(`road.ts`)**: 아스팔트 보수 패치·유분·바랜 구간, 보도 구간 명암·때, 공통 29 m 거시 명암. 추가 텍스처 표본 없음.
5. **젖음**: `WeatherParams.wetness`(0..1, core 공개 계약에 추가) → render `EnvUniforms.wetness`(`weather/wetness.ts`).
   흡수율별 알베도 ↓(최대 55 %), 수막 거칠기 ↓, 수평 포장면 물웅덩이(noiseBank 3채널, 젖음 0.35부터). sim이 값을 만들기 전(M06)엔 0.
   디버그 `?wet=0..1` + 슬라이더, 골든뷰 `weather: 'rain'` = 0.85.

## 성능 경로(1440p, RTX 3050 Laptop, gpu-timer, 같은 세션 A/B)
| 변형 | 차도 지면 / 저층 주거 / 스크램블 (ms) |
|---|---|
| T04 지형(1표본) | 21.4–22.1 / 25.4–25.9 / 24.0–25.3 |
| 첫 구현(ALU PCG 노이즈 ≈ 160 해시/픽셀, 표본 12) | 37.0 / 36.0 / — |
| 노이즈 텍스처 | 25.5 / 30.7 / 30.1 |
| 채택(노이즈 묶음 4표본 + 법선 1표본 + triplanar 끔) | 22.9–23.1 / 27.5 / 26.2–26.3 |
| + triplanar 알베도 | 23.7–25.0 / 28.2–29.2 / 27.6 |
어느 한 부분만 빼도 ≈ 3 ms씩 줄던 구간이 있었다(레지스터 압박·점유율 절벽으로 추정) → 라이브 값을 줄이는 쪽(법선 1회 변환·표본 수)으로 정리.
지형 순증 ≈ +1.2–1.8 ms. T07 깊이 프리패스(가려진 지면 셰이딩 제거)에서 다시 잰다.

## Consequences
- 빌드 크기: MVP L0 122.3 → 132.9 MB(+8.6 %, 차도 경계 1 m 세분이 대부분 — 4 m 완화는 0.85 MB만 줄였다). HLOD 불변. 첫 로드 MB는 staging에서 측정(PR·PROGRESS).
- 도로 가장자리는 1 m 래스터 계단이 남는다(대각 도로). 곧은 연석은 M05-T01 도로 메시가 해결.
- 7 plaza가 녹지·공원까지 덮는다(요요기 공원이 콘크리트색) — M05 토지이용·식생 데이터 전까지 알려진 한계.
