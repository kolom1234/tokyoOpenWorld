# ADR-0034: 실내 매핑 — 자체 생성 큐브맵 배열과 유리 셰이딩 (M03-T05)
- Status: Accepted
- Date: 2026-09-29

## Context
07 §5-4: 창 = 유리 반사 + 실내 매핑(실내 큐브맵 8종, 창별 해시) + 블라인드. 사진·외부 실내 에셋은 라이선스 규칙(실제 상표·저작물 금지)과
전송 예산 때문에 쓰지 않는다. three KTX2Loader는 큐브 배열을 다루지 않는다. 파사드 셰이더는 이미 1440p ≈ 4.7 ms(ADR-0030)라 비용이 민감하다.

## Decision
1. **자체 생성**: 파이프라인 `materials`가 방 8종(사무 4·주거 4, `interior-rooms.ts` — 상자 가구·천장 조명판·바닥 무늬)을 방 중심에서
   6면 광선 추적(`interiors.ts`, 창 쪽 주광 + 천장 조명 + 모서리 AO·접지 그림자, 결정론) → 256² PNG 48장 → **2D 배열**(레이어 = 방 × 6 + 면)
   ETC1S sRGB 1장 `interiors.ktx2`(0.14 MB) + manifest `interiors`(방 id·평균색). 머티리얼 캐시 해시에 생성기 판(`INTERIOR_VERSION`) 포함.
2. **셰이더**(`facade/interior.ts`): 방 = 베이 폭 × 층고 × 깊이(사무 7 m, 주거 4.5 m). 앞면 좌표 + 시선 → 상자 교차 → 방향 → 면·(s, t)(파이프라인
   `faceDir`의 역, 테스트로 고정) → 명시 LOD(`fwidth` 기반, 면 경계 이음새 없음). 방 = hash(창 셀) — 사무 45/20/25/10 %, 주거 균등, 좌우 반전 50 %.
   **유리 픽셀에서만 동적 분기**(`Fn`/`If`, 미분은 분기 밖): 전 픽셀 계산 대비 1440p ≈ −1.2 ms. 베이가 ≈ 3 px 미만이면 방 평균색.
3. **유리**(`glass.ts`): 실내는 발광 채널 — 실내 × (1 − 프레넬) × 투과율(일반 0.8, 커튼월 0.35) × `interiorExposure`(0.02: 낮 실내는 어두운 유리 너머로
   희미하게 — 0.35는 창이 흰색). 블라인드는 유리 안쪽 확산면(바깥 햇빛을 받으므로 알베도, 살 무늬). 반사는 PBR 스페큘러(환경 프로브, SSR은 T07).

## Consequences
- 파사드 비용(1440p, 도청 면 가득, 무제한 프레임): 단색 대비 ≈ 6.0 ms(T04 4.7 ms → +1.3 ms). T07 깊이 프리패스로 재측정.
- 가구는 방 중심 시점으로 구운 것이라 비스듬히 보면 벽에 그려진 듯 보인다(큐브맵 실내 매핑의 알려진 한계).
- 야간 점등(방별 밝기·색온도)은 M09 — `InteriorSample.room`을 노출해 둠.
