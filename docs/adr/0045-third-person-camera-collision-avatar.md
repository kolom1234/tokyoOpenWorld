# ADR-0045: 3인칭 카메라 충돌(부채꼴 sphereCast + 회전 속도 상한)·자체 절차 아바타 (M04-T05)
- Status: Accepted
- Date: 2026-09-30

## Context
09 §3 ThirdPersonRig: sphereCast 충돌, 가까우면 아바타 디더 페이드. 수락 = 좁은 골목에서 카메라 벽 관통 0. 물리는 워커에 있어 질의가 비동기(≈ 1프레임).
첫 구현(목표 시선 방향 1개만 질의, 방향이 12° 넘게 다르면 지금 길이 유지)은 실제 GPU 골목 검사에서 **관통이 났다**(예: 붐 2.19 m인데 피벗 0.2 m 뒤에 벽 — 빠르게 홱 돌릴 때
스무딩 시선이 프레임마다 수십 ° 움직여 지난 결과가 다른 방향 것이 됨). 09 §3 아바타는 "Quaternius 베이스 아바타" — 외부 다운로드가 필요하다.

## Decision
1. **physics `sphereCast(originWF, dir, radius, maxDist)`**(08 §10): 워커 `CastShape`(구, 삼각형·볼록 양면), distance = 구 중심 이동 거리, 시작부터 겹치면 0. 레이 결과와 같은 `RayHit`(재질 = userData 하위 8비트).
2. **3인칭 카메라 회전 상한 프레임당 8°**(≈ 480°/s @60 fps) — 다음 프레임 시선은 이번 시선 ±8° 안.
3. **부채꼴 5개**(가운데·yaw ±8°·pitch ±8°) 붐을 매 프레임 sphereCast(반경 0.2 m > 근평면 0.1 m, 여유 0.05 m) → 최솟값 = 다음 프레임 한계. 결과가 한 스텝 넘게 늦으면
   한계·지금 길이 중 짧은 쪽, 두 스텝 넘으면 최소 0.25 m. 당기기 즉시, 풀기 4 m/s(튀지 않게). 시점 전환·재배치 때 0.25 m에서 다시.
4. **아바타 = 자체 제작 절차 마네킹**(render `scene/avatar.ts`: 캡슐 몸통·팔다리, 구 머리, 외부 에셋·라이선스 없음). 속력으로 연속 블렌드: 팔다리 진자 진폭 0.32·v(≤ 0.75 rad),
   주기 = v / 1.4 m(≤ 1.6 Hz), 1.8 m/s부터 앞 기울기(≤ 0.18 rad), 대기 호흡. 붐 0.5 → 1.2 m에서 opacity 0 → 1(alphaHash 디더). 1인칭에선 숨김, freecam에선 세워 둔 바디를 대기 자세로.
   공개 계약: core `AvatarState`, traversal `TraversalService.avatar`, render `setAvatar` — 배선 `wiring/camera.ts`. Quaternius 모델 교체는 **다운로드 승인 뒤**(파일·출처·크기 확인, 03·ATTRIBUTION 갱신). **→ ADR-0048(2026-10-01): Quaternius 모델로 교체, 마네킹은 적재 전·실패 시 대체.**

## Consequences
- 수락(실제 GPU, MVP `?world=local`, 보행 봇이 찾은 막다른 골목 8곳 × 25 s — 느린 회전·한 프레임 90–180° 홱 돌리기·걷기·휠 줌, 매 프레임 피벗 → 실제 카메라 구(0.1 m) 캐스트):
  **12,600 프레임·검사 10,083회 관통 0**(고치기 전: 관통 발생). 아바타 페이드 프레임 4,881(골목 벽 근접).
- 빠른 마우스 홱 돌리기는 3인칭에서 최대 480°/s로 따라간다(1인칭은 제한 없음).
- 워커 질의가 프레임당 5개 늘었다(구 캐스트 ≈ 수십 µs).
