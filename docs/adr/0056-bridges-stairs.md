# ADR-0056: 교량·보도육교 = PLATEAU brid 면(overrides 스트림 + 정밀 충돌), 계단 = 상판에 닿는 OSM `highway=steps`(챌면 메시 + 램프 프록시) + 계단 통로 교량 면 걷어내기 + 램프 위 수평 속력 유지·공중 카메라 연속 (M05-T08)
- Status: Accepted
- Date: 2026-10-02

## Context
M05-T08: PLATEAU brid(보도육교·교량 상판·계단) normalize → 렌더 + 충돌. OSM `highway=steps`·`footway bridge=yes` → 계단마다 JCOL 램프 프록시(flags bit0, 위 한쪽 면 triMesh),
렌더는 챌면 ≤ 0.20 m 스텝 메시. 수락 = 시부야역 주변 보도육교 계단 왕복(봇) 끊김 없음(1/6 s 창 수평 ≥ 0.9 m/s)·낙하 0, 카메라 프레임당 < 3 cm(M04-T04 ⚠️ 데이터 몫, ADR-0044).
MVP 구역 PLATEAU brid: 시부야 8 + 신주쿠 7 파일 → 교량 86동(41셀). 시부야 역 데크·보도육교는 평평한 상판(계단 없음), 新都心歩道橋는 계단을 **속이 찬 블록**(지면 ~ 상판 벽 + 비탈 지붕)으로 둔다.
OSM 계단 선은 PLATEAU 상판과 어긋난다(끝점이 상판 안쪽 3.8 m까지 들어가거나 상판 가장자리 밖 1–2 m).

## Decision
1. **리더·정규화**: `brid:Bridge` → `BridgeRecord`(`BuildingRecord`와 같은 모양, `layer: 'bridges'`). 테마면: `OuterFloorSurface`·`RoofSurface` → roof(걷는 상판 윗면), `OuterCeilingSurface`·`GroundSurface` → ground,
   `WallSurface` → wall, `BridgeConstructionElement`·`BridgeInstallation` → installation. `normalize --layer plateau --plateau-layer brid`로 교량만 다시 정규화 → `data/normalized/bridges/`.
   원천 = PLATEAU zip의 `udx/brid/*_op.gml`(fetch 미구현 — 04 §4.1 규칙대로 zip에서 해제).
2. **교량 렌더·충돌**(`build/overrides/bridges.ts`): 소유 셀의 overrides.mesh 스트림(UV 0) — 윗면·옆면 콘크리트, 아랫면 짙은 데크, 구조재 금속. 충돌 = 면 그대로 지면 triMesh 스트림에
   (건물 충돌의 0.3 m 단순화를 거치면 상판 가장자리·난간이 사라진다). closure 제외.
3. **계단 명세**(`derive/stairs.ts`): 지상 계단 선(터널·실내·음수 layer·level 제외) 중 **한 끝 이상이 상판(평평한 roof 면, 높이 폭 ≤ 1.5 m)에서 2 m 안**인 것만. 끝 높이 = 상판 또는 셀 지형.
   타당성: 높이 차 0.5–10 m, 평균 경사 ≤ 45°(시부야에서 수도고 상판 31 m에 잘못 붙는 계단 등을 버림). 두 끝 모두 지형인 계단(공원 비탈)은 건드리지 않는다(지형이 이미 이어진 경사).
   아래 → 위 정렬, **상판에 처음 들어가는 곳에서 자름**(0.25 m 간격, 높이만큼 수평 이후 — 상판 밑을 지나면 머리가 걸린다), 착지판 = 진행 방향 상판 안까지 + 0.5 m. 소유 = 선 중점 셀.
4. **계단 메시·충돌**: 챌면 n = ⌈H / 0.20⌉ 균등(디딤판 + 챌면), 옆 판(0.12 × 0.4 m)·손스침(1.0 m), 착지판(상판 3 cm 아래 — 틈이면 보인다).
   충돌 = JCOL triMesh **램프 프록시**(flags bit0, 위를 향한 한쪽 면, 계단 정거장 + 평평한 착지판) + 양옆 벽 박스(1.1 m, 구간마다 경사 따라 기울임 — 떨어짐 방지).
5. **교량 면 걷어내기**(`build/overrides/carve.ts`): ① 면 중심이 계단 통로(반폭 + 0.6 m, 아래 끝 ~ 위 끝 + 착지판) 안이고 모든 꼭짓점이 반폭 + 1.6 m 띠 안 → 통째로 버림
   (PLATEAU 계단 블록 — 상판 윗면·위 끝 너머 아랫면은 남김). ② 계단 위 끝 "문"(끝 0.6 m 앞 ~ 착지판, 계단 폭)을 가로지르는 면(상판 가장자리 난간·슬래브 옆면 — 가장자리 전체가 긴 폴리곤 하나)
   → 수직 평면 2개로 계단 폭 + 0.2 m 띠만 잘라낸다. 통로 = 이웃 셀 소유 계단 포함(지면 = 영역 DEM, 같은 판정 — 만들지 않는 계단은 걷어내지 않는다).
6. **물리**(`physics` character): 램프 프록시 바디(userData = 재질 | flags << 8, bit 8) 위 접지 중엔 수직 속도 = −(n·h)/n_y(수평 속력 유지). Jolt 접촉 투영만으로는 오르막 수평이
   ≈ v·cos²θ(28° 계단 1.35 → 1.0 m/s — 1/6 s 창 최소 0.86 m/s로 수락 미달). 박스 연석·계단 모서리(기울어진 접촉 법선)에선 하지 않는다(튀어 올라 카메라 4.5 cm/프레임).
7. **카메라**(`traversal` first-person-rig `followFeet`): 공중 프레임에 스냅하지 않고 **남은 오프셋을 둔 채 몸과 함께** 움직인다(위치 연속, 낙하 지연 누적 없음) — 착지 뒤 스프링이 풀되
   첫 프레임 카메라 속도는 ≤ 1 m/s(낙하 속도를 넘기면 몸 아래로 파고든다, ≤ 3 cm). 헤드밥은 공중 0.3 s 미만이면 이어 간다.
   (공중에도 같은 스프링을 오프셋에 걸던 중간안은 지면 모드 스프링 속도 = 카메라 절대 속도를 넘겨받아 램프 끝에서 상승 속도가 두 배 — 3.2 cm.) 이전: 램프 끝에서 1–4프레임 뜰 때 스프링 지연(≈ 2v/ω = 11 cm)만큼 + 헤드밥 리셋 3 cm가 한 프레임에 튀었다.
8. `footway bridge=yes` 단독(PLATEAU 상판 없는) 육교는 만들지 않는다 — MVP 구역 보도육교는 PLATEAU brid에 있다(⚠️ 23구 확장 때 다시 본다).

## Consequences
- **MVP**(`20261001-b779645-03883ce7`, validate 0): 교량 86동, 계단 65(챌면 1,620), 걷어내거나 자른 교량 면 3,105. overrides.mesh 473만 → 482만 삼각형(셀 최대 46k),
  L0 236.7 → 238.2 MB(+0.6 %), 셀 충돌 삼각형 최대 27k. staging 첫 로드 21.4 MB·첫 표시 13.8 s. 걷기 봇 5분 × 3(스폰 2 + 시부야 동쪽 보도육교 반경 45 m) 낙하 0·끼임 0. 골든뷰 docs/screenshots/M05/T08(`footbridge-shibuya`·`footbridge-shinjuku` + 코어 4).
- 로컬 실측(실제 GPU Chrome, 스폰 3×3 + 新都心歩道橋 3×3 로컬 빌드, 계단 봇 = 실제 W 입력 + 포인터 조향, rAF를 감싸 프레임마다 최종 상태 기록, 왕복 2회):
  | 계단 | 1/6 s 창 수평 최소 | 카메라 프레임당 최대(60 fps 환산 / 원값·긴 프레임 포함) | 낙하 | 최대 공중 |
  |---|---|---|---|---|
  | 시부야역 동쪽 보도육교(OSM w284152573, ≈ 6 m 상승) | 1.17 m/s | 1.54 cm / 3.8 cm(≥ 41 ms 프레임) | 0 | 0 ms |
  | 新都心歩道橋 직선(w245762053, 5.1 m·28°) | 1.15 m/s | 1.52 cm / 2.97 cm(34 ms 프레임) | 0 | 100 ms |
  | 新都心歩道橋 곡선 3구간(w245762059, 6.1 m) | 1.21 m/s | 2.53 cm / 2.78 cm | 0 | 167 ms |
  원값이 3 cm를 넘는 건 렌더 끊김 프레임(33–50 ms)에서 정상 상승 속도(0.7 m/s)만큼 움직인 것뿐이다. 수정 전: 오르막 수평 최소 0.86 m/s, 램프 끝 카메라 11.8 cm.
- 시부야 西口 보도육교는 OSM 계단 두 끝이 모두 같은 상판(2 m 스냅) 안이라 평면 → 계단을 만들지 않는다(PLATEAU 상판 그대로 걷는다).
- 계단 블록을 걷어낸 자리에 PLATEAU 블록 일부(통로 띠 밖 옆벽)가 남을 수 있다 — 계단 옆 벽처럼 보인다.
- 램프 위 오르막 수평 속력이 평지와 같아져 카메라 수직 속도 = v·tanθ(28° 0.72 m/s = 60 fps 1.2 cm/프레임). 스프링 지연은 비탈 위에서 ≈ 11 cm 그대로(위 끝에서 부드럽게 따라잡음).
- 교량·계단은 L0 overrides에만 있다(HLOD L1+ 없음) — 보도육교는 L0 거리 밖 원경에서 보이지 않는다(폭 2–4 m, 상공 400 m 조망에서 1–2 px).
- ⚠️ freecam이 상판 슬래브(두께 ≈ 1 m) 안에 들어가면 검은 면이 보이고 블룸을 켜면 화면 전체가 검다(NaN 의심 — 걷기 카메라는 들어갈 수 없는 위치). 원인 조사는 별도 작업.
