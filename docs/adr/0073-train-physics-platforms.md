# ADR-0073: 열차 물리 — 메인 → physics 칸 레코드(보간 MoveKinematic), 승강장·홈도어 = rail.bin 승강장 + 런타임 생성, 선로 위 건물 충돌 제외
- Status: Accepted (M07-T04)
- Date: 2026-10-05

## Context
M07-T04 Do: 차량 키네마틱 바디(바닥·벽), 문 바디 개폐, 홈도어 모델·연동, sim→physics 30 Hz 목표 전송 + 물리 측 보간. Accept: 정차 중 승차, 주행 중 차내 보행 시 캐릭터 미끄러짐·관통 0.
08 §8 초안은 sim.worker → physics 직결 포트였지만 열차 위치는 메인 스레드에서 계산한다(ADR-0072). 승강장 바닥은 셀 데이터에 없다(OSM 승강장은 T01 정차 계산에만 썼다).
실제 GPU: 4개 역 모두 PLATEAU 역 상옥·역사(운수 431·불명 461)·선로 위 빌딩(신주쿠 남쪽 133.7 m)이 땅~지붕 막힌 껍질로 선로를 덮는다 — 16동, 선로 표본 6–446 m.

## Decision
1. **칸 레코드**(core `TRAIN_BODY_STRIDE` = 10: id(편성 일련 × 32 + 칸), x,y,z(WF 레일 윗면), yaw, pitch, 차형, 종류, 문, 예약): 게임 `trainPhysicsSystem`(phase 25)이 플레이어 60 m 안 칸을
   `sim.trainBodies` → `physics.setTrainCars`(step 명령 — 같은 프레임 마지막 것). 메인 프레임마다(≈ 60 Hz, 30 Hz 이상).
2. **물리 칸**(`worker/train-bodies.ts`): TRAIN 키네마틱 합성 바디 = 바닥·천장·끝벽·옆벽(문 자리 비움)·문 위 벽·롱시트(0.45 m — 계단 0.40 m보다 높다)·운전실 칸막이, 차형 치수 = core `TRAIN_CAR_TYPES`
   (render 모델과 공유). 쪽마다 닫힌 문 바디(열림 ≥ 0.9면 없음). 스텝마다 목표 = 직전·이번 레코드 선형 보간(시각 = step targetS) → `MoveKinematic`.
3. **캐릭터 바닥 속도**(`character.ts`): 접지면 `UpdateGroundVelocity` → 지면 속도(접점 — 곡선 회전 포함)를 수평에도 더한다. 이동 입력 = 바닥 기준 상대 속도(정지 지면은 0이라 기존 동작 그대로).
4. **승강장**: 파이프라인이 정차마다 OSM 승강장 고리(선 승강장 = 선로 반대쪽 3 m 띠)·윗면(레일 윗면 + 1.1 m)을 rail.bin `platforms`·정차 `platform` 번호로(메타 JSON 추가 필드 — 형식 v1 유지, 옛 파일 = []).
   sim `rail/platforms.ts`: 귀 자르기 삼각화(윗면 +Y·옆면 바깥) → render 정적 메시(열차 머티리얼 재사용)·physics 정적 묶음 'rail-platforms'(윗면만 — 가장자리에서 떨어질 수 있다).
5. **홈도어**: 탑승 노선(rideable)의 정차마다 선로 중심 2.05 m(승강장 쪽), 편성 길이 + 2 m — 편성 문 위치마다 2 m 문(문짝 2장, 미닫이 0.93 m), 사이 = 1.3 m 고정 판 조각(≤ 2 m, 곡선 따라).
   문 열림 = 그 정차에 선 열차의 문(sim이 프레임마다). physics: 고정 판 'rail-psd-panels' + 닫힌 문 'rail-psd-gates'(열림 상태가 바뀔 때만 다시).
6. **선로 위 건물**(`build/rail-buildings.ts`): 바닥 다각형이 선로 표본 ≥ 3개(6 m)를 덮는 건물 = 충돌 제외(렌더 유지 — 차내 캐릭터가 역 통과 중 건물 면에 밀리지 않게),
   그중 431·461 용도·높이 ≤ 12 m = 승강장 지붕 → 렌더도 제외.

## Consequences
- 수락(실제 Jolt, 같은 스레드 워커): 0.83 m/s² 가속 → 15 m/s + 반경 300 m 곡선 12 s 동안 선 승객 미끄러짐 최대 **1.75 cm**(< 5 cm), 주행 중 닫힌 문으로 걸어도 간격 **0.020 m**(캐릭터 패딩 — 관통 0)·
  끝벽 간격 0.117 m, 정차 중 열린 문으로 승강장 → 차내(바닥 1.15 m) 승차 ✅, 닫힌 문은 문 바깥 −1.745 m에서 멈춤 ✅.
- 승강장 11개(MVP): 시부야 야마노테 섬식 = 두 선로 공유. 홈도어 = 야마노테 8정차 × 44문.
- 역사·선로 위 빌딩 껍질은 렌더에 남아 역에서 열차가 건물 안으로 들어가 보인다(⚠️ — 상옥 높이 ≤ 12 m만 제거). 대안: PLATEAU 역사 LOD2 면을 선로 회랑에서 잘라 내거나(벽 제거·지붕만) 역 오버라이드(ADR-0053 방식)로 역사를 다시 짓는다 — M07-T06/M12.
- 승강장은 OSM 윤곽 그대로 평평(경사·계단 없음) — 개찰구·출입구 동선은 M07-T06.
