# ADR-0033: 부팅 첫 표시 전 적재를 준비 집합으로 한정 (whenReady exclusive)
- Status: Accepted
- Date: 2026-09-29

## Context
14 §2 초기 다운로드 ≤ 60 MB(부팅 완료 시 전송 바이트). M03-T06에서 처음 staging에 M03 클라이언트를 올려 재니 79.0 MB(첫 표시 10.7 s).
같은 클라이언트에 M02 데이터도 77.0 MB → 데이터(+2 MB)가 아니라 클라이언트 원인. 첫 표시 조건(스폰 384 m L0 `live`)은 렌더 적용(프레임 예산)에
묶여 있는데, M03의 무거워진 첫 프레임들(선컴파일·대기 LUT·그림자) 동안 네트워크는 관심 집합 전체(L1–L3·먼 L0)를 계속 받았다.

## Decision
`WhenReadyRequest.exclusive?: boolean`(streaming 공개 계약 추가). exclusive 대기자가 있는 동안 재계산은 **대상 셀만 새로 요청**하고,
대상 밖 `queued`(fetch 전)는 내린다(fetch 중인 것은 유지). 대기자가 끝나면 다음 재계산이 관심 집합을 평소대로 요청한다.
game `showWorld`의 스폰 대기만 exclusive. 순간이동 대기는 그대로(이미 떠 있는 월드 유지가 우선).

## Consequences
- staging 초기 다운로드 79.0 → **12.7–13.4 MB**, 첫 표시 10.6–11.2 s(변화 없음). 골든뷰(완전 안정 뒤 캡처) 영향 없음.
- 첫 표시 직후 원경(HLOD)이 1–2 s 디졸브로 채워진다(전엔 첫 표시 전에 받아 둠). 로딩 화면 연장 여부는 UI(M04+)에서.
- 첫 표시 자체(≈ 11 s)는 12 s 목표에 가깝다 → 선컴파일 병렬화·대기 LUT 선계산은 T07/T08에서.
