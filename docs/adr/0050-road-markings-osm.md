# ADR-0050: 노면 표시 = OSM 기반 파생(횡단보도·정지선·차선·「止まれ」) + decals.mesh + 알파 테스트 마모 (M05-T02)
- Status: Accepted (수락 ⚠️ — 위치 정확도는 OSM 한계)
- Date: 2026-10-01

## Context
04 §4.3: OSM lanes/turn:lanes + 도로 폴리곤 → 차선(흰 실선/점선, 황색), 정지선, 일본식 횡단보도(측선 없는 사다리형, 0.45 m 줄·간격), 「止まれ」 자체 폰트 메시, 마모 마스크.
PLATEAU tran(MVP)은 차선(1010)·횡단보도 면이 없다(차도 1000·교차부 1020·보도 2000·섬 3000뿐). 수락 = 스크램블 교차로(대각선 포함) 형태가 항공사진과 ≤ 0.5 m.

## Decision
1. **OSM 원천**: Geofabrik 간토 2026-09-29판 고정(sha256 lock), 파이프라인 이미지에 osmium-tool 1.19. `normalize --layer osm` = extract(영역 + 500 m, smart) → tags-filter(도로·횡단·방호·나무·공원·소품·교량)
   → GeoJSONSeq → WF(@sanpo/geo) → L0 셀 버킷(선·면 = 닿는 모든 셀, 점 = 소속 셀). 레코드 태그는 쓰는 키만(ODbL 파생 DB 최소화).
2. **파생**(`derive/markings/*`, 셀 소유 = 조각 중심이 셀 안):
   - 횡단보도: `footway=crossing` 선(무표시 제외) — 차도에 처음 들어가는 점부터 0.45 m 막대·0.45 m 간격, 막대 길이 = 폭(`width` > 신호 횡단 6 m > 4 m), 막대 조각은 차도 위만.
   - 차선: `lanes ≥ 2` 차도 선을 1 m마다 PLATEAU 차도 좌우 가장자리까지 행진(0.25 m) → 차로 폭 = 폭 ÷ 차로 수를 2.75–3.5 m로 자르고 묶음을 차도 가운데.
     좌측통행(진행 방향 차로 = 선 왼쪽), 중앙선 = 4차로 이상 황색 실선·그 밖 흰 실선, 같은 방향 경계 = 흰 점선 5/5 m, 폭 0.15 m. 교차부(1020)·횡단 띠 ± 1 m에서 끊는다.
   - 정지선(0.45 m): 신호 횡단 띠 × 차도 선 교차점 상류 (띠 반폭 + 2 m), 진행 차로만(일방 = 전폭), 교차부 안이면 없음. `highway=stop` 점 = 5 m 안 차도 선, 방향 = `direction` 태그
     또는 가까운 선 끝(교차점) 쪽, 상류 3 m에 「止まれ」(자체 획 폰트 3글자, 차로 가로·진행 방향 2.5 m로 늘림).
   - 기하 = 1 m 칸 사각형, 높이 = **완성 지형 메시 + 2 cm**(RTIN 5 cm 오차와 무관), 위에서 CCW.
3. **렌더**: `decals.mesh`(POSITION u16 + 노드 변환, NORMAL i8, `_PAINT` u8 → f32), 머티리얼 `road_marking` — 도료 색(흰·황) × 때, 노이즈 3축척 마모 = 알파 테스트
   (벗겨진 곳은 버려 아스팔트가 보임), 젖으면 거칠기 ↓. 그림자 받음·드리우지 않음. 선컴파일 목록에 추가.
4. **ODbL 표기**: 화면 오른쪽 아래 상시 `© OpenStreetMap contributors`(credits.ts, M08 크레딧 전까지), ATTRIBUTION(content·world-mini), TKC 섹션 sources `osm-kanto`.
5. **검증**: `checks/markings-photo.ts`(컨테이너) — GSI seamlessphoto z18 타일(data/raw 캐시, **검증 전용·굽지 않음**)에 띠를 겹쳐 그리고(PHOTO_DEBUG),
   띠마다 ±2 m 이동 대비(차도 표본만) 최대 위치를 잰다.

## Consequences
- 스폰 3×3: 셀당 데칼 1.1–5.6k 삼각형, decals.mesh 21–47 KB, 횡단 막대 14–266·정지선 0–72·止まれ 0–4/셀. world-mini 4.98 → 5.18 MB(한도 6 MB로 조정).
- ⚠️ **수락(≤ 0.5 m) 미달**: 사진 대조 그림에서 스크램블 5방향 횡단·대각선이 제자리에 있으나 OSM 선 자체가 **대각선 ≈ 2 m·동쪽 ≈ 1.5 m** 어긋남(서·북·남은 ≈ 0.5 m 안).
  자동 최대 대비 이동은 1.3–2.8 m로 나오나 z18(0.49 m/px)에서 0.45 m 줄무늬가 겨우 분해돼 지표 자체가 불안정. 스크램블 주변엔 PLATEAU 교차부(1020)도 없어 기하 정렬 불가.
  대안: (a) OSM 원본을 GSI 사진 기준으로 고쳐 기여(외부 편집 — 사용자 결정), (b) M05-T05 랜드마크 오버라이드로 스크램블 노면 표시를 수작업 기하로(측량·공공 자료 기준),
  (c) 더 높은 해상도 공공 정사영상이 있으면 검증 재실시.
- 차선은 OSM 선 위치·차로 수 태그 품질에 좌우(좁으면 생략). 좌·우회전 화살표(`turn:lanes`)·버스 정류장 표시·자전거 도로 표시는 미구현.
