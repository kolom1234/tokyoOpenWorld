# ADR-0081: 역 동선 = 실물 개찰구(충돌·플랩·합성음) + 계단 입구 F 페이드 이동 + 섬식 승강장 레일 높이 맞춤
- Status: Accepted (M07-T06)
- Date: 2026-10-12

## Context
M07-T06 Do: 개찰구 게이트(플랩 애니메이션, 자체 효과음), 역 출입구·플랫폼 동선 확인, 역 앰비언스. Accept: 하라주쿠역 출구→플랫폼→탑승 동선 막힘 없음.
실제 GPU 조사: 하라주쿠 섬식 승강장(OSM 고리, 윗면 = 레일 + 1.1 m)은 거리(다케시타 출구 쪽 T.P. ≈ 32.6 m)와 선로로 떨어져 있고 계단·콘코스 기하가 없다.
또 같은 승강장을 쓰는 두 선로(내회·외회)의 DEM 표본 레일 높이가 1.3 m 달라, 승강장 높이를 먼저 만든 선로 기준으로 정한 탓에 다른 선로 열차 바닥이 승강장보다 1.44 m 높았다(걸어서 못 탐).

## Decision
1. **역 접근 정의** `content/stations/access.json`(수작업, 가상 배치): 출구별 개찰구 줄(중심·들어가는 방향·통로 수)·개찰구 안 계단 입구·승강장 계단 발치. MVP = 하라주쿠 다케시타 출구 4통로.
2. **개찰구**(apps/game `station/layout.ts` 순수 배치): 캐비닛 0.2 × 1.2 × 1.0 m, 통로 0.75 m(넓은 개찰구 — 캐릭터 캡슐 Ø 0.5 m가 지나간다), 양 끝 2.5 m 낮은 울타리. 렌더 = `RenderService.setStationFixtures`(인스턴스 상자·팔레트 색, 로고·글자 없음)
   + `setGateFlaps`(통로별 열림 — 플랩이 캐비닛 쪽으로 접힘), 물리 = 정적 묶음 `stations`(캐비닛·울타리). 걷기로 통로 선을 건너면 카드 접촉 + 날개 열림, 1.35 s 뒤 닫힘(합성음, ADR-0079). 요금 체계 없음.
3. **계단(⚠️ 기하 없음)**: 계단 입구·발치 표식(어두운 바닥 판 + 노란 테두리 + 파란 안내판) 1.6 m 안에서 F → 0.3 s 페이드 → 반대쪽 표식 앞으로 이동(도착 높이 = 물리 하향 레이 첫 면). 안내는 임시 DOM 글(HUD = M08).
4. **승강장 높이 맞춤**(파이프라인 `build/rail-platform-align.ts`): 승강장마다 정차 선로들의 레일 윗면 평균을 목표로, 승강장 길이 + 20 m 안은 목표 높이, 바깥 120 m에 걸쳐 원래 높이로 선형 복귀(≤ 1.1 %), 승강장 topY = 목표 + 1.1 m.
5. **역 소리**: 승강장 표식 160 m 안에서 이 역이 다음 역인 열차가 다가오면 자작 역 차임 1회, 정차 열차 문 열림·닫힘 = 문 차임(70 m 안), 차내 = 다음 역이 바뀔 때 LCD 알림·정차 때 문 차임. 역 존 베드·실내 잔향은 ADR-0079.

## Consequences
- 수락: 실제 GPU 봇 — 거리 → 개찰구 통과(걷기) → 계단 F → 승강장 → 정차 열차 문으로 걸어 들어가 F 탑승(PR 본문).
- 한계: 계단·콘코스는 페이드 이동(후속 — 역 내부 기하 태스크), 출구는 하라주쿠 1곳만, 개찰구 위치·통로 수는 실제와 다를 수 있다.
  레일 높이 맞춤은 선로 표본 높이를 바꾸므로 선로 메시·역 벽 자르기·승강장 메시가 함께 움직인다(같은 빌드에서 일관).
