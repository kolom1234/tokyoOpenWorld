# ADR-0077: 구름 = 공중원근 뒤 하늘 화소 2D 층(고도 1.6 km, fbm 4옥타브) + 같은 잡음의 CPU 짝으로 태양 가림, 볼류메트릭(Ultra)은 보류
- Status: Accepted (M09-T02)
- Date: 2026-10-11

## Context
M09-T02 Do: 2D 레이어 구름(조명 반영) + Ultra 볼류메트릭(1/4 해상도 + 재투영), cloudCover 연동, 태양 가림 → 조도 감쇠. Accept: 볼류메트릭 ≤ 2.5 ms(Ultra), 2D ≤ 0.5 ms.
하늘은 씬 패스에 없고 후처리 공중원근(aerial, 깊이 = 하늘)이 그린다 → 씬 안 반투명 구름 판은 하늘이 아니라 검정과 섞인다.

## Decision
1. **2D 층**(`post/weather-sky.ts weatherSky`): 공중원근 결과(노출 전)의 하늘 화소에서 시선을 고도 1.6 km 평면과 교차 → 값 잡음 fbm 4옥타브(2.4 km 축척, 상공 바람 = 지상 × 4로 흐름).
   덮임 문턱 = 0.75 − 0.5 × cloudCover(fbm 분포 ≈ 0.5 ± 0.12 → 덮인 비율 ≈ 구름량), 지평선 페이드. 밝기 = 그 화소 하늘 휘도 × (얇은 2.2 … 두꺼운 밑면 0.75) + 태양 쪽 은빛 —
   대기 모델의 절대 단위 없이 하늘과 어울리고, 흐린 날은 하늘 전체가 회색이 된다(태양 원반도 가린다).
2. **연무**(같은 패스): 거리 지수 감쇠, 밀도 = 안개² × 0.005 + 비 mm/h × 1.2e-4(1/m), 색 = 자동 노출이 잰 장면 평균 휘도 × 1.5(CPU — 30프레임마다). 밤에는 구름 밑면·연무에 주황 도시 불빛 반사(장면 평균 휘도 비례).
3. **태양 가림**: CPU에서 셰이더와 같은 잡음(three TSL `hash` PCG를 JS로 복제 — `tslHash`, 씨앗 < 2^24로 float32 정확)을 태양 방향에 평가 → 직사광 = 1 − 0.88 × max(태양 쪽 덮임, 구름량²).
   구름이 흘러가면 그림자 대비가 바뀐다(ADR-0076의 고정 감쇠 대체).
4. **볼류메트릭(Ultra) 보류 ⚠️**: 레이마치 + 1/4 해상도 재투영은 TAAU·동적 해상도와 이력 관리가 겹치고(이 PC 1440p Ultra 여유 없음 — ADR-0035·0039), 이번 큐 범위(T01–T05·M07-T06) 안에서 2D 층으로 대체.
   대안 = takram `@takram/three-clouds`(WebGPU 판이 나오면) 또는 별도 태스크(M11 성능 여유 확인 뒤). Ultra도 2D 층을 쓴다.
5. 소프트웨어 래스터(CI)는 이 합성을 끈다(픽셀 비교 e2e 결정론·비용).

## Consequences
- 수락 측정(실제 GPU, PR 본문): 2D 층 비용 ≤ 0.5 ms 목표. 볼류메트릭 ≤ 2.5 ms는 미구현 ⚠️.
- 한계: 구름은 평평한 한 층(두께·입체 그늘 없음), 상공에서 구름 위로 올라가도 아래에서 본 모양, 구름 그림자는 직사광 전체 감쇠(지면 패턴 아님).
