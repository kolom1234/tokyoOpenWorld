# ADR-0087: 승용차 물리(WheeledVehicleController)·운전 모드·플레이어 차 렌더·차 부르기
- Status: Accepted (M08-T01)
- Date: 2026-10-17

## Context
- M08-T01: 가상 소형 세단(08 §6 표)을 Jolt `WheeledVehicleController`로, 우핸들 운전석 시점·계기판·등화. 수락 = 0→100 km/h 10–13 s, 60 km/h 급제동 건조 14–20 m·젖은 노면 증가.
- 비폭력 탐방 게임 — 파손·사고 연출 없음(AEB·보행자 회피는 T02).

## Decision
1. physics: 플레이어 차 = VEHICLE 동적 강체(하부 상자 바닥 틈 0.18 m + 무게중심 0.5 m로 낮춤) + `VehicleConstraint`(원통 캐스트 접지, 앞 조향·앞 굴림, 안티롤 앞뒤).
   파라미터는 전부 `content/vehicles/sedan.json`. 운전자 보조는 워커 스텝마다: ABS(바퀴 종 슬립 > 0.15 → 제동 × 0.8), TCS(4 m/s 이상·구동 슬립 > 0.25 비례), 속도 감응 조향(100 km/h 40 %), 속도 제한 120 km/h.
   스냅샷 = 바디 기록 뒤 차량 칸 4개(속력·rpm·기어·flags·실제 스로틀·바퀴 4 × 6).
2. 실측에서 찾은 것(Node·실제 Jolt 조정):
   - Jolt 기본 마찰 결합 √(타이어 × 바디)는 셀 콜라이더 기본 마찰 0.2에서 접지력이 45 % → `VehicleConstraintCallbacksJS.GetCombinedFriction` = 타이어 곡선 × 젖음 배율(바디 마찰 무시).
   - Jolt 바디 선형 감쇠 기본 0.05/s는 90 km/h에서 1.2 m/s² "저항" → 0, 대신 공기 ½ρ·CdA·v²(0.65 m²) + 구름 0.012·mg.
   - 엔진 각감쇠 0.2는 고회전 토크의 ≈ 25 % → 0.05. TCS 반감(> 0.2)은 출발을 막아 비례·저속 제외로.
   - 제동 1500 Nm 균등은 뒤가 먼저 잠겨 20 m+ → 앞 2200·뒤 1100 Nm(문서 08 §6 갱신). 비례 ABS는 더 길었다(20.5 m) → 단순 해제.
3. traversal drive 모드: W 가속, S 제동(멈추면 후진), 정지 유지 제동, 키보드 조향 램프, L 전조등, Q/E 방향지시등(꺾었다 풀면 꺼짐), V 추적 ↔ 운전석(우핸들), F 하차(멈춘 뒤, 운전석 쪽 아래 레이 → walk exact).
   추적 카메라 피벗 1.6 m·카메라 2.2 m(09 §3 초안 1.6 m는 붐 구가 차체 상자 안에서 시작해 지붕 위로 붙었다). 앞 셀 콜라이더 없으면 멈춰 기다림.
   walk → drive 때 걷는 캡슐을 치운다(서 있던 자리에 남으면 출발하는 차를 막는다).
4. render: 플레이어 차 = 교통과 같은 가상 절차 모델·머티리얼(LOD0 단일 인스턴스 메시 + 메시 변환 — 경사·기울기 그대로), 머티리얼 1개 공유, 장면 밖 선컴파일. flags bit3 = 전조등 켬(낮에도).
   도장 = 가상 카셰어(흰 차체 + 청록 띠) — 로고·번호판·브랜드 없음.
5. game: `vehicles/`(player-cars·curb-spot·drive-hud·wiring). 차 부르기 = walk R(패드 D-pad ←) → 3×3 셀 연석 차선(laneIdx 0, 교차로 9 m 밖)에서 진행 방향 왼쪽으로 비킨 자리. 스폰 프리셋 `vehicles`.

## Consequences
- Node(실제 Jolt, 평지): 0→100 km/h 12.4 s, 60 km/h 제동 건조 18.8 m·젖음(마찰 × 0.7) 27.4 m, 조향·후진 테스트 통과. 실제 GPU 주행 봇 수치는 PR.
- ⚠️ 운전석 시점: 실내·계기판 모델 없음(흰 보닛이 화면 아래 ⅓, 계기판은 HUD). 바퀴 앞바퀴 조향·서스펜션 상하는 렌더하지 않음(차체 자세만). 전조등 빛(노면 조명) 없음 — 발광만(조명 풀 재컴파일 문제).
- 교통 AI는 아직 플레이어 차를 모른다(T02).
