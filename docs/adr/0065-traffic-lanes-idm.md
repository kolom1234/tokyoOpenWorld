# ADR-0065: 교통 — OSM 간선 차선 그래프(lanes.bin v2·셀 포털)·IDM·좌측통행 양보·신호 연동 칸·주축 우선 현시
- Status: Accepted (M06-T05)
- Date: 2026-10-04

## Context
M06-T05 Do: 차선 그래프 생성·셀 포털 연결, IDM, 회전 선택, 좌측통행 양보 규칙, 스폰/디스폰. Accept: 메이지도리 10분 시뮬레이션 교착 0, 신호 위반 0, 평균 속도 제한속도의 40–80 %.
05 §7 lanes.bin v1(노드 id + portalKey, 신호 그룹 u16 표)은 생산자가 없었다. 신호 코드(ADR-0062)는 교차로 ID × 16 + 계획 × 4 + 그룹(ID 20비트)이고 기본 계획 오프셋 = ID 해시(무작위).

## Decision
1. **차선 생성**(`tools/pipeline/src/stages/derive/lanes.ts` + `lanes/{graph,geometry}.ts`, `build/lanes-cell.ts`): 영역(셀 + 8-이웃) OSM trunk·primary·secondary·tertiary(+_link,
   고가·지하·고속도로 제외) 선 → 좌표 키(1 cm)로 위상 복원(정규화에 노드 id 없음) → 가장자리. 방향별 차로: 양방향 도로 = 진행 방향 **왼쪽 절반**(좌측통행), 일방통행 = 선 중심,
   차로 0 = 연석 쪽, 폭 3.0 m. 교차점(가지 ≥ 3)마다 정지선을 뒤로 물림(가장 넓은 도로 반폭 + 신호면 6 m·아니면 1.5 m, 4–25 m), 연결로 = 2차 베지어 — 직진(±35°) 차로 대응,
   **좌회전 = 연석 차로**(20 km/h), **우회전 = 안쪽 차로**(25 km/h), 유턴 없음. 신호 교차점 = 신호 점·신호 횡단 30 m 안, 정지선 코드 = 소품 차량 신호기와 같은 사이트·규칙
   (8 m보다 짧은 가장자리 — 분리 차로 사이 — 끝엔 신호 없음). 셀 사각형으로 잘라 경계 = **포털 노드**(키 = 차선 id + 교차점 좌표 해시 — 이웃 셀이 같은 키).
2. **lanes.bin v2**(05 §7 갱신): 노드 16 B `{u32 key, f32 x,y,z}`(모든 노드 = 글로벌 키, 런타임이 키로 병합), 차선 28 B `{u32 id, u32 from, u32 to, u8 kind(0 도로·1 연결로·2 버스),
   u8 turn(0 직진·1 좌·2 우), u8 speedKmh, u8 laneIdx, u32 signal(코드 | 0xFFFFFFFF), u32 ptOffset, u16 ptCount, u16 widthCm}`, 점 f32 xyz. 그룹 표 삭제.
3. **신호 코드 배치 변경**(ADR-0062 보완): `((ID 14비트 × 64 + 오프셋 칸 6비트) × 16) + 계획 × 4 + 그룹`(< 2^24). 오프셋 칸(2 s) = −(교차로 주축 A 방향 위치) ÷ 12 m/s mod 주기 —
   같은 간선의 교차로가 녹색 물결(系統制御 근사), 사이트 계획 = 0. **주축 A = 둘레 OSM 차도 선 길이 × 등급 가중**(trunk·primary 4, secondary 3, tertiary 2, 그 밖 1)의 히스토그램 봉우리
   (등급 없이는 메이지도리가 교차로마다 A·B로 갈렸다). 기본 계획 = A 녹 67 s(보행 A 62 + 점멸 5)·B 43 s(38 + 5) + 황 3·전적 2 ×2 = 120 s(간선 우선).
4. **런타임**(sim.worker, `traffic/*`): `lane-graph`(셀 청크 → 전역 차선·노드 키 병합, 다음 차선 = 끝 노드의 나가는 차선), `idm`(T 1.5·a 1.2·b 2.0·s0 2.0·δ 4, 제동 하한 −9),
   `routing`(직진 0.6·좌 0.25·우 0.15 가중, 차선 진입 때 두 개 앞까지 미리 고름), `yielding`(가상 정지 지점: 적신호, **황색은 3 m/s²로 설 수 있을 때만**·못 서면 통과 약속,
   셀 경계 조각 너머 정지선도 미리 봄, 교차로 출구에 자리 없으면 진입 안 함, 우회전 = 대향 직진(45 m 안·1.5 m/s↑) 양보, 연결로·출구 8 m·앞 22 m 위 보행자(군중 출력 격자 + 도로 위 플레이어)),
   `spawner`(차종 7 — 세단 26·택시 24·경차 16·경트럭 8·미니밴 14·택배 트럭 8·버스 4 %, 색 32·씨앗, 원하는 속력 = 제한 × 0.85–1.1; 플레이어 400 m 안 도로 차선, 처음엔 어디든·평소엔
   250 m 밖 또는 시야 뒤, 앞뒤 12 m 비고 **신호 정지선 60 m 앞 제외**), 500 m 밖·막다른 끝 제거, 신호 대기 아닌데 150 s 정지 = 교착(제거). 감시 = 적신호 통과 수·교착 수·평균 속도 비율 누적.
   출력 = 두 번째 SAB(용량 160, 칸 = x,y,z·yaw·속력·바퀴 회전·variant(차종 3비트·색 5비트·씨앗)·flags(제동·좌우 깜빡이)). 조정값 = `content/sim/traffic.json`(최대 150, 정오 배율 0.6).
5. game: `wiring/streaming-sim.ts` 반경 448 m로 `nav.bin` + `lanes.bin` → `sim.addCell(key, nav, lanes)`, `SimService.outputs()`(보행자·차량 버퍼). 차량 렌더·물리 동기 = T06.

## Consequences
- **수락(단위, world-mini 실데이터 10분, 차량 40대)**: 교착 0 ✅, 적신호 통과 0 ✅. 메이지도리(50 km/h 도로 차선) 평균 속도 = 제한의 **0.37** ⚠️(목표 0.40–0.80) — 신호 없으면 0.82,
  즉 120 s 주기·회전 연결로 감속·512 m 영역 가장자리(나가는 차선이 적은 교차로)에서 잃는다. 연동 오프셋·주축 우선은 거의 효과 없음(긴 240 m 구간에서 정지 확률 지배).
  80대면 0.26(작은 망에 과밀). 대안: 실제 신호 현시 데이터(공개 없음), 차량 감응식, MVP 큰 망에서 재측정.
- **실제 브라우저**(로컬 9셀, 정오 90대 + 보행자 950): 워커 틱 p95 2.2–2.7 ms(군중 + 교통), 위반 0·교착 0, 전체 차선 평균 속도 비율 0.56–0.74(대기열이 쌓이며 내려감).
- 생활도로(보차 공용, ADR-0063)에는 차가 없다 — 보행자와 차가 만나는 곳은 횡단보도·회전 연결로뿐. 신호 코드 배치가 바뀌어 옛 빌드(코드 없음·ID 20비트)와 섞이면 오프셋이 다르다 → MVP 전체 재빌드.
