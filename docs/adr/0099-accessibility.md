# ADR-0099: 접근성 마무리 — 모션 민감 기본값·UI 애니메이션, 배율 150 % 레이아웃 검사, 효과음 자막, 색각 보정
- Status: Accepted (M11-T04)
- Date: 2026-10-19

## Context
- M11-T04 수락: 모션 민감 옵션 전부 동작, UI 배율 150 %에서 레이아웃 깨짐 0. 12 §6: 자막(안내 차임·중요 효과음), 색각 보정 LUT 3종, 모션 민감(헤드밥·모션 블러·FOV 효과), UI 배율 80–150 %.
- M10 상태: 모션 민감 = 헤드밥·운전/자전거 속도 FOV·열차 진동만(traversal `motionEffects`). 자막·색각 보정 없음. 배율 150 %에서 HUD 겹침(지명 ↔ 역 안내, 운전 계기판 ↔ 도움말·안내, 안내 ↔ 알림 — px 고정 위치), 지도 화면 레이어 선택 넘침·조작 안내 ↔ 출처 띠 겹침.

## Decision
1. **모션 민감**: 기본값 = OS `prefers-reduced-motion`(저장된 설정이 없을 때만), UI 전환·깜빡임 애니메이션도 끈다(`#ui.reduce-motion`). 모션 블러는 렌더 경로에 없다.
2. **레이아웃 검사 = e2e**(`tests/e2e/layout-probe.ts` + `ui-scale.spec.ts`, 샌드박스 `&scale=1.5`): 화면 밖(스크롤 컨테이너는 가로만)·글 잘림·컨트롤 겹침(스크롤로 가려진 부분 제외)·떠 있는 글 겹침·가로 스크롤. 메뉴 7화면 × 3개 언어 × 1024×768·1280×720, HUD 운전(경고 전부)·운전 + 알림·열차·알림 + 자막. CI 시간 ≈ 25 s.
3. **HUD 배치**: 아래 안내·알림 위치를 em(배율 따라감)으로, 운전·자전거 중에는 안내·알림·자막을 위쪽(역 안내 아래)으로. 역 안내 띠는 상단 줄 아래, 지명은 말줄임. 계기판 폭 상한(도움말과 안 겹침). 지도 화면 조작 안내는 오른쪽 패널 아래, 축척은 왼쪽 위.
4. **효과음 자막**: AudioService를 Proxy로 감싸(`apps/game/src/captions.ts`) 중요 효과음 재생 때 HUD `caption`을 민다(듣는 사람 30 m 안, 같은 자막 2 s 안 반복 없음). 표시는 설정 '효과음 자막'(기본 끔). 오디오 패키지 API는 그대로.
5. **색각 보정**: render `setColorVision('off'|'protan'|'deutan'|'tritan')` — Machado 2009(심도 1.0) 시뮬레이션 S와 오차 재분배 D로 (I + D(I − S))를 선형 HDR에 곱한다(출력 단 유니폼, 재컴파일 없음, 끔 = 단위 행렬). "LUT 3종"을 3D LUT 대신 3×3 행렬로(같은 효과, 텍스처·비용 없음).

## Consequences
- 수락: e2e `ui-scale.spec.ts` 3개 통과(배율 150 %, 문제 0), 대조(800×500 — 지원 밖)에서는 37건 잡음. 모션 민감은 단위 테스트(traversal `motionEffects`·settings 적용) + UI 클래스.
- 색각 보정은 직접 렌더(WebGL2 폴백·CI)에는 적용되지 않는다. 사람 눈 확인(색각 시뮬레이터)은 후속.
- 자막 목록에 보행 신호 유도음·엔진은 없다(오디오 내부 재생) — 필요하면 audio API에 이벤트 추가.
