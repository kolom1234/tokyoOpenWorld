# ADR-0038: 정지 화면 떨림 — GTAO 고정 노이즈 + 5×5 깊이 인지 블러, 정지 떨림 e2e (M03 보강 1)
- Status: Accepted
- Date: 2026-09-29

## Context
staging에서 화면 전체(특히 원경·배경)가 떨린다는 보고. 후보: TAAU 지터 누적 실패, 동적 해상도 배율 변동, 자동 노출 깜빡임, 카메라 정밀도.
실측 방법(RTX 3050 Laptop, Chrome WebGPU, 1920×1080): `?debug=1` 핸들로 카메라를 프레임마다 고정·회전(0.1°/프레임)·이동(0.1 m/프레임) →
게임 루프 콜백 **직후 같은 프레임에** 캔버스를 복사(rAF를 rAF 밖에서 등록하면 루프 뒤에 실행된다) → 연속 40프레임 휘도 차(정지 = 1차, 움직임 = 2차 차분),
화면 위 40 %(하늘·원경)·가운데 30 %·아래 30 %로 나눠 평균 |Δ|와 4·12 단계 초과 비율.

요인 분리(High, 스케일 0.85 고정, 정지, 요요기 상공 300 m 근경 평균 |Δ|):
| 조건 | 근경 | 가운데(스카이라인) |
|---|---|---|
| 기본(GTAO 시간 필터) | 0.597 | 0.356 |
| TAA 끔 | 0.003 | 0 |
| AO 끔 | 0.045 | 0.150 |
| SSR·Bloom·자동 노출·그림자 끔 | 변화 없음 | 변화 없음 |
| 렌더 스케일 0.5 / 1.0 | 0.566 / 0.590 | 0.310 / 0.367 |

→ 떨림은 TAA 지터에서만 생기고(끄면 0), 그중 대부분은 **GTAO `useTemporalFiltering`**: 프레임마다 방향·오프셋을 돌리는 노이즈(12프레임 주기)를 TAAU가 섞도록
설계됐지만, TAAU 분산 클리핑이 이웃 분산 안에서 노이즈를 따라가 정지 화면에 반짝임이 남는다. 노출 변화 ≤ 0.03 %, 원점은 2 km 안(정밀도 무관), 동적 해상도는 1080p High에서
0.5 바닥에 붙어 7–43 s마다 0.5↔0.55를 오간다(선명도 변동 — 항목 2 성능 개선으로 해결할 문제).

## Decision
1. GTAO = **고정 노이즈**(`useTemporalFiltering = false`, 8표본, 반경 0.5 m) + `post/ao-filter.ts` **5×5 깊이 인지 블러**(AO 해상도 RTT, 이웃 viewZ가 중심과 5 % + 5 cm 넘게 다르면 가중 0).
   GTAO 노이즈 타일은 5×5 마방진이라 평면에서 패턴이 정확히 상쇄된다. 고정 노이즈만 쓰면 도로에 얼룩 패턴이 보이고, three `DenoiseNode`는 +6 ms에 효과가 비슷해 버렸다.
   동적 해상도는 블러 RTT 배율도 같이 바꾼다.
2. TAAU 분산 감마를 넓히는 패치(정지 1.0 → 1.5: 원경 반짝임 −20 ~ −30 %)는 **채택 안 함** — three 패치 유지 비용, 느린 이동(M04 도보)에서 고스팅 위험.
   `depthThreshold`·`edgeDepthDiff`는 영향 없음(히스토리 무효화가 원인이 아님), `currentFrameWeight` 0.01은 −30 %지만 수렴·고스팅이 느려져 보류.
3. 회귀 방지 e2e `tests/e2e/flicker.spec.ts`: CI(SwiftShader)는 후처리를 끄므로 `RenderConfig.debugForcePost`(`?forcePost=1`)로 GTAO + TAAU(Medium)를 켜고
   480×270(≈ 10 FPS)·그림자·동적 해상도 끔, 40프레임 수렴 뒤 연속 8프레임 → 중앙값 평균 |Δ| ≤ 0.15, >4 단계 ≤ 0.7 %, 전역 평균 변화 ≤ 0.1.
   SwiftShader 실측: 수정 전 0.204·0.90 %(실패), 수정 후 0.115·0.44 %, AO 끔 0.11, TAA 끔 0.001.

## Consequences
- 수정 전후(High 0.85 고정, 1080p, 평균 |Δ| (>4 단계 %)): 정지 요요기 근경 0.592(3.14) → 0.082(0.02), 스카이라인 0.353(1.30) → 0.217(0.35),
  정지 스크램블 원경 0.113(0.44) → 0.037(0.02), 이동 요요기 근경 1.41(9.1) → 0.44(1.3), 회전 요요기 근경 6.25(35.5) → 4.84(20.5).
- 남은 떨림: 원경 수평선 근처 서브픽셀 건물 윤곽의 TAAU 재구성 반짝임(>12 단계 0.047 % 픽셀) — TAA 고유 한계. 대안: 분산 감마 패치(위 2), 원경 HLOD 윤곽 사전 필터링.
- GTAO 시간 누적이 없어져 AO가 약간 더 부드럽다(블러). AO 비용: 블러 RTT(¼ 픽셀 × 25탭) 추가 — 항목 2 성능 표에 포함.
