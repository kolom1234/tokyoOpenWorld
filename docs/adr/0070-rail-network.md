# ADR-0070: 철도 망 파생 — OSM 선로 이름 + N02 대조, 좌측통행 방향, global/rail.bin v1, 셀 선로 메시는 overrides.mesh
- Status: Accepted (M07-T01)
- Date: 2026-10-05

## Context
M07-T01 Do: N02 노선 식별 + OSM 선로별 폴리라인 → 방향별 스플라인, 높이(지상/교량/터널), 곡률 제한속도, 플랫폼·정차 위치, `global/rail.bin`. 선로·도상·가선주 메시는 셀에.
Accept: 시부야–신주쿠 야마노테 선로가 항공사진과 ≤ 1 m, 정차 위치가 플랫폼 중앙 ±2 m.
조사: PLATEAU 시부야 zip에 철도(rwy) 층 없음(원격 중앙 디렉터리 확인 — bldg·brid·tran·frn·veg 등만). N02(2025년도판, CC BY 4.0)는 노선 단위 중심선(1/25,000 기반)이라
선로별이 아니다. OSM 간토 추출본은 선로마다 name이 있다 — 山手線(야마노테 본선 2선)·山手貨物線(사이쿄·쇼난신주쿠, 신주쿠 대가드 교량 구간은 湘南新宿ライン)·東京メトロ銀座線.
야마노테 OSM 선 113개의 끝점 차수 = 1이 4개뿐 → 끝점 공유 사슬이 정확히 2선로(각 9.3 km, 추출 범위 = MVP + 1.5 km).

## Decision
1. **원천**: `fetch --source ksj-n02`(N02-25 zip sha256 lock, RailroadSection·Station GeoJSON) + `normalize --layer rail`(osmium tags-filter `nwr/railway`·`public_transport=platform,station,stop_position`, 한 파일).
   노선 목록 `content/sim/rail-lines.json`(OSM name 집합·N02 노선/사업자·노선색·편성·정차역·방향 이름 — 야마노테 북행 = outer(外回り)).
2. **선로**: 노선 이름이 맞는 본선(service 없음) way를 끝점 공유로 잇는다(갈림은 가장 곧은 쪽, 45° 초과 금지), 300 m 미만 버림, 남 → 북 정렬 후
   **좌측통행**: 두 선로 중 북행 기준 왼쪽(서) = 북행, 오른쪽은 뒤집어 남행(점 순서 = 진행 방향). 꼭짓점 플래그 = 속한 way OR, 구간 = 양끝 AND(터널·교량).
3. **표본**: 구심 Catmull-Rom → 호 길이 0.5 m 재표본. 높이 = 지형(dem_1m, 범위 밖 원경 DEM) + 0.5 m(레일 윗면), 교량·터널 구간은 양끝 지상 높이 선형 보간(DEM은 교량 밑 도로·터널 위 지표),
   ±20 m 이동 평균. 제한속도 = min(노선 최고, √(0.8 R)), R = ±15 m 방향 변화, ±창 최솟값.
4. **정차**: OSM 승강장(선·면) 꼭짓점을 선로에 투영 — 가까운 변 ≤ 4.5 m·같은 쪽·겹침 ≥ 60 m → s = 겹침 가운데(편성 중심), 문 쪽 = 승강장 쪽, 역 = 이름 맞는 OSM 역 점 ≤ 450 m. 역마다 가장 붙은 승강장.
5. **rail.bin v1**(05 §9): 메타 JSON + f32 표본·제한속도 + u8 플래그, 빌드 전역(`global/`, publish 포함). sim·traversal·render가 읽는다(T03~).
6. **셀 메시**: roads.mesh(보도 전용 `_SURF` 형식) 대신 **overrides.mesh 랜드마크 스트림**(`_LMAT` 자갈·콘크리트·짙은 강판) — 렌더 머티리얼·선컴파일 추가 없음.
   도상 사다리꼴·침목 0.6 m·레일 2줄(노선 궤간)·가선주 50 m(진행 방향 왼쪽 2.7 m = 좌측통행 바깥)·가동 브래킷·전차선 5.2 m, 교량 상판, 터널 제외. 충돌 없음(열차는 키네마틱, 도상 0.3 m).
   `build`가 셀보다 먼저 rail.bin을 만든다(`buildArea` — outDir를 비운 뒤).

## Consequences
- MVP 6선로: 야마노테 outer/inner 9.3 km(터널 224–233 m·교량 451–514 m), 화물선 north/south 9.2 km, 긴자선 2 × 3.9 km(대부분 터널 — 시부야 고가만 보임). 89,865 표본(0.5 m).
- **정차**: 시부야·하라주쿠·요요기·신주쿠(야마노테 양방향), 시부야·신주쿠(화물선), 시부야(긴자선) — 승강장 최소 면적 사각형 중심 투영과 **0.01–1.15 m**(수락 ±2 m ✅). 승강장 길이 215–355 m(11량 220 m).
- N02 대조: 선로 표본(10 m) → 같은 노선 N02 중심선 평균 4.7–9.5 m(N02 정밀도 범위 — 식별 확인용).
- **항공사진 ⚠️**: 거울 대칭 중심 400표본 중앙값 0.5 m, p90 1.2 m(탐색 한계), 1 m 초과 15 %. 0.49 m/px에서 궤간이 2 px라 지표가 약하고, 초과 표본은 시부야역 데크·고층 그늘 구간에 몰린다
  (검토 PNG). 대안: 고해상도 정사영상(유료)·초과 구간 수동 보정 파일(횡단보도 보정과 같은 방식, ADR-0058).
- 높이: 교량·터널 끝 보간이라 긴 고가(긴자선 시부야)와 굴곡 교량은 실제 상판과 다를 수 있다 — PLATEAU brid 상판 대조는 후속.
- 셀 삼각형 +34k(4선로)·+48k(시부야 6선로) — 예산 400k 안.
