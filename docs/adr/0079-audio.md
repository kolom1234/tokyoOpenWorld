# ADR-0079: 오디오 = Freesound CC0 녹음 베드·발소리(파이프라인 가공 → R2 공유 에셋 지연 로딩) + 위험 범주 자체 합성 + 셀 audio.json 32 m 격자 존
- Status: Accepted (M09-T04)
- Date: 2026-10-12

## Context
M09-T04 Do: 버스 구조, 존 크로스페이드, 가려짐 로우패스, 발소리 재질 매핑, 보행 신호 유도음 합성, CC0 소스 기록. Accept: 존 경계 이동 시 클릭/끊김 0, ATTRIBUTION 누락 0.
사용자 결정(2026-10-11): CC0·CC BY 녹음 사용 승인(파일별 질문 없음). 환경음은 품질 좋은 녹음 우선, 신호 유도음·개찰구음·차임·LCD 안내음처럼 실물 재현 우려가 있는 것은 자체 합성.
출처·작성자·라이선스·원본 URL 자동 기록. CC BY-NC·BY-SA·출처 불명 금지. 실제 발차 멜로디·안내방송·상업 음악·브랜드 효과음은 녹음·재현 모두 금지.
압축 포맷으로 줄이고 큰 파일은 저장소가 아닌 R2 공유 에셋, 첫 로드 60 MB 예산 밖 지연 로딩.

## Decision
1. **원천**: Freesound 검색(CC0 필터) → `content/audio/library.json`(원천 22 — 전부 CC0, 작성자·제목·페이지·미리듣기 URL) + 출력 역할(베드 15·발소리 7).
   파일 = HQ 미리듣기 MP3(로그인 없이 받을 수 있는 공개 CDN, 원본은 계정·API 키 필요) — sha256은 `data/sources.lock.json` `freesound-audio`. `ATTRIBUTION.json` `fs-<id>`는 스크립트로 생성,
   파이프라인 테스트가 원천마다 항목·라이선스·URL 일치를 검사(누락 0).
2. **가공**(`pnpm pipeline audio`, 컨테이너 ffmpeg 8 + libopus): 베드 = 원천에서 길이 30–60 s 구간 후보 중 **지속 음조**(같은 주파수 칸 6프레임+ 봉우리 에너지 비 — 신호음·차임·멜로디·음악이 걸린다)
   + 순간 큰 소리(1 s RMS 최대/평균)가 가장 적은 곳 → 1.5 s 등전력 교차 루프 → RMS −24 dBFS(피크 −1) → Opus 64 kbps 스테레오.
   발소리 = 온셋 검출 → 걸음 ≤ 10(피크 중앙값 가까운 것, 0.42 s 이하, 끝 페이드) → 한 파일 + 오프셋 → Opus 48 kbps 모노. 결과 22파일 **5.04 MB** → 빌드 `shared/audio/`(manifest.json),
   publish가 R2로(`audio/ogg`). 게임은 unlock 뒤 필요한 베드만 받는다(첫 로드에 0 B).
3. **합성(녹음 금지 범주)**: 음향식 보행 신호 유도음 = "새 울음(삐-요 상승·하강 0.9 s)"·"뻐꾸기(두 음 하강 1.6 s)" 매개변수 음형, 신호 코드 그룹 짝·홀로 방향 구분, 보행 W일 때만(점멸 F·적 D 멈춤).
   개찰구 날개(쉭+멈춤 잡음)·카드 접촉(완전5도 화음)·거부(두 음 하강)·역 차임(자작 3음 상행)·LCD(두 음 하행)·문 차임(같은 음 세 번)·열차 주행음(레일 25 m 이음매 "타탄" 4회·모터 톱니파)·엔진.
   실제 기기·사업자 음과 음높이·리듬을 다르게 골랐다(재현 아님).
4. **존**(파이프라인 `derive/audio-zones.ts` → 셀 `audio.json`): 32 m 칸 규칙 — station(역 60 m·승강장) > crossing(보행 신호 기둥 40 m 안 4+) > park(OSM 공원·녹지 / 나무 10+) > shopping(간판 3+·상점 1층 2+)
   > elevated(고가 선로) > alley(주택·맨션 3+, 평균 15 m 미만) > street(기본, 존 없음). 같은 행 연속 칸 = 직사각형. 발음체 = 보행 신호 4개+ 교차로의 기둥마다 signalTone(셀 ≤ 96).
5. **런타임**(`@sanpo/audio`): 첫 제스처 전에는 AudioContext를 만들지 않는다. 존 가중 = 원반(반경 14 m) 표본 32점(황금각)의 포함 비율 → 베드 목표 이득 표(낮/밤·매미 7–9월·풀벌레 8–10월·비 mm/h·우산·바람·고도 25–150 m 페이드·실내 빗소리 차단)
   → GainNode setTargetAtTime(τ 0.8 s)만. 3D = PannerNode HRTF inverse(ref 2 m, rolloff 1.2), 풀 32·빼앗기, 가려짐 = physics 레이캐스트 4 Hz → 로우패스 1.2 kHz. 잔향 = 절차 IR(실외 0.9 s·실내 2.6 s, 역 가중으로).
   좌표 = WF − 1024 m 격자 원점. 볼륨 `[`·`]`(±10 %)·`\`(음소거) + localStorage, `?vol=`·`?audio=0`.

## Consequences
- 사람 귀 검수가 최종 판정 — 자동 음조 검사는 신호음·차임·음악 구간을 피하게 할 뿐 말소리 속 안내방송을 완전히 가려내지 못한다(역 베드는 안내방송 없는 실내 홀 녹음으로 대체).
  문제가 있는 베드는 library.json에서 원천·구간을 바꾸고 `pnpm pipeline audio --update-lock` 다시.
- 미리듣기 MP3(≈ 180 kbps) 원천이라 원본보다 고역이 약간 손실 — 앰비언스 용도로 충분. 원본이 필요하면 Freesound API 키(OAuth) 도입.
- 존은 규칙(가상) — 실제 소리 지도 아님. 엔진음은 drive 모드가 생기면 연결.
