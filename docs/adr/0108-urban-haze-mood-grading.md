# ADR-0108: 도시 연무(광선 해석 적분) + 분위기 그레이딩(4 프리셋 가중 LUT)
- Status: Accepted
- Date: 2026-11-26

## Context
- 맑은 날 원경이 너무 선명하고 납작했다(그래픽 분석 D4): 대기 모델(takram)의 Mie 에어로졸은 매우 깨끗한 공기(연직 광학 깊이 ≈ 0.005)이고, `weather-sky.ts`의 연무 밀도는 맑은 날 0이었다(비·안개만). 도쿄의 실제 에어로졸 광학 깊이는 0.2–0.3 수준, 시정은 겨울 맑은 날 수십 km·습한 여름 10–20 km.
- 3D LUT는 "도쿄 낮" 하나뿐이라 흐린 날·황혼·밤에도 같은 대비·채도였다(07 §7 "시간·날씨 LUT 전환"은 미구현).
- 제약: 서버·데이터 0, 결정론(시각·날씨만), 메인 스레드 호출당 ≤ 4 ms, 실사 사진(사용권)은 아직 없음.

## Decision
1. **도시 연무**: 소광 β(z) = β₀ e^(−z/H), H = 1 km(경계층). 광선 광학 깊이를 해석 적분 τ = β₀ e^(−h₀/H) · d · (1 − e^(−k))/k, k = d_y·d/H.
   하늘 광선은 40 km(경계층을 벗어나며 포화 → 지평선 뿌옇고 천정 맑음), 지면 화소는 깊이 거리. 투과율 e^(−τ)로 연무 색과 섞는다.
2. β₀ = 계절 코사인(1월 15일 1.0e-4 → 7월 중순 2.4e-4 /m, Koschmieder 시정 ≈ 39 ↔ 16 km) ÷ (1 + 풍속/6 m/s). 연무 색 = 장면 평균 휘도 × (0.94, 0.97, 1.03), 낮에는 태양 쪽 전방 산란 (1 + 0.6 cos⁶).
3. **분위기 LUT**: 프리셋 4종 — 낮(M03-T07 값 그대로)·흐림/비/안개·황혼(태양 고도 0–11°)·밤. 가중 = 밤 > 흐림(구름^1.5·비/2 mm·안개 중 최대) > 황혼 > 나머지 낮, 합 1.
   파라미터를 섞고, 양자화 키가 바뀌면 임시 버퍼에 z 조각 4개씩(프레임당 p99 ≈ 1.3 ms) 구워 다 되면 한 번에 교체(최소 0.5 s 간격).
4. TSL 주의: `If` 블록 안에서 처음 빌드된 표현식은 선언이 블록에 갇힌다 → 광선 값(`dir`·`dist`·`sky`)을 블록 앞에서 `toVar()`로 확정(안 하면 블록 밖 연무가 잘못된 값 → 하늘 NaN → 검은 하늘이었다).

## Consequences
- 항공·원경에 거리감(지평선 연무)이 생기고, 월드 가장자리(데이터 끝)도 연무에 묻힌다. 하늘 천정은 거의 그대로(지평선만 희게).
- 낮 LUT 결과는 이전과 비트 단위로 같다(테스트). 흐림·황혼·밤은 새 그레이딩.
- 그레이딩은 실사 사진 측정이 아니라 근거 있는 절차값이다 — 사용권 있는 참조 사진(자체 촬영)이 생기면 프리셋을 사진 통계(휘도 분포·채도·색온도)로 다시 맞춘다(14 §4 fidelity-review).

## Alternatives
- takram 대기 모델의 Mie 계수 자체를 키우기 → 하늘·태양 원반·직사광 색까지 전부 바뀌고 LUT(사전 계산) 재계산 비용 → 기각(연무는 후처리 한 줄).
- 거리 지수 안개(높이 무관) → 하늘 천정까지 뿌옇게 된다 → 기각.
- LUT 여러 장을 GPU에서 섞기(3D 텍스처 4장 샘플) → 화소당 샘플 4배, 셰이더 변형 증가 → CPU 재굽기(드묾)로 대체.
