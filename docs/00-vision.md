# 00 — Vision & Scope

## 1. 한 문장
"지금 도쿄의 거리를 그대로 걷는 느낌" — 실측 데이터 기반 도쿄를 자유롭게 탐방하는 사실주의 산책 시뮬레이터.

## 2. 디자인 필러 (우선순위 순)
1. **Fidelity of Place (장소의 정확성)**: 건물 배치·높이·도로·고저차·철도·가로수 위치가 실측 데이터와 일치. 창작은 "데이터가 없는 디테일"에만 한다.
2. **Presence (현장감)**: 물리 기반 조명/대기, 시간·날씨·계절, 군중·교통·전철의 생활감, 환경음.
3. **Calm Exploration (여유로운 탐방)**: 목표 강요 없음. 발견(POI 도감), 포토모드, 자유 이동.
4. **Maintainability (지속 가능성)**: 데이터 파이프라인 재현성, 모듈 경계, 문서 우선 개발.

## 3. 비목표 (Non-Goals) — 구현하지 않는다
- 전투, 레이스, 경쟁, 점수, 파괴, 차량 손상, 범죄 시스템
- 멀티플레이 (MVP 이후 ADR로 재검토 가능)
- 건물 내부 전체 재현 (예외: 역 콘코스/플랫폼, 소수 랜드마크 로비는 M12 이후 검토)
- 실제 상표 로고·점포 간판의 복제, 실존 인물
- 모바일 최적화 (데스크톱 우선; 모바일은 Low 티어로 "동작만" 목표)

## 4. 플레이 경험
| 활동 | 설명 |
|---|---|
| 도보 산책 | 1인칭/3인칭 전환. 보도·계단·육교·에스컬레이터. 신호 대기. 스크램블 교차로 횡단 |
| 전철 탑승 | 역 개찰 → 플랫폼 → 탑승 → 차창 풍경 → 하차. 실제 노선·역 위치, 시간표 기반 운행 |
| 운전 | 일반 승용차(우핸들, 좌측통행). 교통 흐름에 섞여 드라이브. 경쟁 요소 없음 |
| 자전거 | 생활형 자전거(마마차리). 골목 탐방용 |
| 자유 비행 | 드론/포토 카메라. 상공에서 도시 조망, 저속 시네마틱 이동 |
| 발견 | 랜드마크·거리·골목·공원 방문 시 도감 등록. 짧은 설명(자체 작성 + Wikidata CC0) |
| 시간/날씨 | 실시간 도쿄 시각 모드 / 자유 설정. 맑음~비~안개. 계절별 가로수 색 |
| 포토모드 | 시간 스크럽, 노출/피사계심도/렌즈, PNG 저장 |

## 5. MVP 범위 (M00–M11)
- **구역**: 시부야역·스크램블 교차로 ↔ 하라주쿠·오모테산도·요요기공원 ↔ 신주쿠역·서신주쿠 초고층가·도청.
  - WF 경계(셀 정렬): `x ∈ [-1792, 1792)`, `z ∈ [-4352, 1024)` → 14 × 21 = 294개 L0 셀(256 m), 약 19.3 km².
  - 위경도 대략: 남서 (35.652, 139.683) ~ 북동 (35.698, 139.718).
- **외곽**: 23구 전역을 HLOD(L2/L3) 저해상도 스카이라인으로 표시 → 신주쿠 고층에서 조망 시 도시가 끊기지 않게.
- **노선**: 탑승 = JR 야마노테선(시부야–하라주쿠–요요기–신주쿠). 시각 전용 = 사이쿄·쇼난신주쿠라인, 긴자선(시부야 고가 구간). 지하 역 내부는 M12 이후. 상세는 `10-simulation.md §6`.
- **차량**: 승용차 1종, 자전거 1종.
- **언어**: 한국어/일본어/영어.

## 6. 성공 기준 (MVP 출시 조건)
1. RTX 3060급/M1 Pro급, 1440p, High 티어에서 스크램블 교차로 한낮 기준 60 fps (p95 프레임 ≤ 20 ms).
2. 콜드 스타트 → 첫 플레이 가능 ≤ 12 s (100 Mbps), 초기 다운로드 ≤ 60 MB.
3. 실측 비교: 랜드마크 20곳의 건물 높이 오차 ≤ 2 m 또는 5% (PLATEAU measuredHeight 기준), 도로 중심선 오차 ≤ 1.5 m.
4. 걷기만으로 MVP 구역 끝에서 끝까지 끊김(로딩 정지) 없이 이동 가능.
5. 크레딧 화면에 모든 데이터 출처 표기 (라이선스 준수 체크리스트 100%).

## 7. 확장 로드맵 (MVP 이후)
M12 긴자·마루노우치·도쿄역 → M13 아키하바라·우에노·아사쿠사 → M14 롯폰기·도쿄타워·오다이바 → 23구 전역 L0.
구역 추가는 파이프라인 `--area` 파라미터와 `data/areas/*.json` 정의만으로 가능해야 한다 (코드 변경 없음이 목표).
